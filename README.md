## 快速上手

- 新人从零开始 / 系统了解 → 先读 [06_使用说明书/07_预备知识入门.md](06_使用说明书/07_预备知识入门.md) 补名词，再按 [06_使用说明书/00_总览与学习路线.md](06_使用说明书/00_总览与学习路线.md) 逐阶段推进（10 册成套见 06 目录）。
- 要改方案 → 只改根目录 `总体方案与执行计划.md`，其余文档一律不改。
- 要训练模型 → 看 `01_视觉感知/数据与训练/v2训练流水线/AutoDL租卡训练指南v2.md`。
- 要连飞控 → 先看 `02_飞控与硬件/调试工具/README.md`（断开 Mission Planner、参数导入两遍）。
- 要改代码 / 跑仿真 → 看 `03_机载软件/README.md`（每版先过 SITL 再上真机）；Gazebo 环境与 SIH 台架在 `04_仿真/`。
- 要了解项目进展 → 看最新的 `07_工作日志/*.md`。

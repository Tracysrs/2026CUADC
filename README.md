## 快速上手

- 新人从零开始 / 系统了解 → 先读 [12_使用说明书/07_预备知识入门.md](产出区/12_使用说明书/07_预备知识入门.md) 补名词，再按 [12_使用说明书/00_总览与学习路线.md](产出区/12_使用说明书/00_总览与学习路线.md) 逐阶段推进（视觉/结构/操作/算法/系统五大模块文档成套见 12 目录）。
- 要改方案 → 只改 `产出区/01_设计/总体方案与执行计划.md`，其余文档一律不改。
- 要训练模型 → 看 `产出区/02_数据与训练/v2训练流水线/AutoDL租卡训练指南v2.md`。
- 要连飞控 → 先看 `产出区/03_工具/飞控调试/README.md`（断开 Mission Planner、参数导入两遍）。
- 要改代码 / 跑仿真 → 看 `产出区/10_机载代码/README.md`（每版先过 SITL 再上真机）。
- 要了解项目进展 → 看最新的 `记录区/09_工作日志/*.md`。

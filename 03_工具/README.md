# 03_工具 · 调试与运维脚本

飞控与机载设备的**调试工具集**。只放可重复使用的脚本，一次性产出写进工作日志。

## 内容

| 目录 | 内容 |
|---|---|
| `飞控调试/` | check_fc（飞控连接）/ check_gps（定位状态）/ verify_params（参数核对）/ activate_lazy_params（懒参数激活）/ read_params（参数读取）五个脚本 |

## 怎么用

连飞控、导参数等操作**先看 `飞控调试/README.md`**，内含用法与踩坑记录（关键三条：操作前断开 Mission Planner、参数要导入两遍、USB 重插后 COM 号会变）。

## 注意

- 脚本输出的参数快照统一存到 `01_设计/参数备份/`，别散落在外面；
- GPS 室外验收标准（3D Fix + ≥8 星 + HDOP<1.5）与罗盘校准是 M1 上真机的前置条件。

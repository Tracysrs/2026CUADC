## 1. 得分模型

| 项 | 满分 | 说明 |
|---|---|---|
| 起飞分 | 50 | 带两瓶水飞越起飞线即可 |
| 空投分 | **800** | 两瓶分别投中 1 号筒(500) + 2 号筒(300)；投同一 A 区只算一次 |
| 侦察分 | 300 | 3 个标识全对；**错一个 −100，不填不扣** |
| 着陆分 | 50 | 螺旋桨停转 + 轴心投影落 ø80cm 圆内 |
| 时间分 | 200 | `200×(300−T)/300`，只有**完赛**才有 |

- 理论上限 ≈**1400**；T=150s 高分线 1250~1300（冲奖目标 1250+）；
- **完赛硬门槛**（缺一项时间分归零）：起飞 + 空投分 ≠0 + 侦察至少对 1 个 + 着陆成功 + 停表前交成绩单；
- → **侦察不是加分项，是通行证；宁可空着不能错填**（拒识策略存在的理由）；
- 分档：保底 ~330（一瓶 B 区 + 侦察对 1 + 落回）｜及格 ~600（一瓶 A 区 + 侦察对 2）｜冲奖 1250+（1 号筒 + 2 号筒 + 全对）；
- **1300 与 900 的差距就是 15cm 小桶**——冲奖前提是投放标定 CEP<5cm 做实。

## 2. 规则硬约束 → 对策（6 条）

| # | 规则要点 | 对策 |
|---|---|---|
| 1 | 进场准备只有 1 分钟，场上不接受维修调试 | 上电即跑：预加载模型 + 黑帧预热 + suspend 唤醒 + systemd 自启（不能 SSH 手拉） |
| 2 | 细则 5.4 允许计算机休眠 | Jetson 预加载后 suspend，唤醒到首帧 <10s |
| 3 | 细则 7.3.2 禁止赛前确定筒位 | 只能机上实时检测，不预标定 |
| 4 | 细则 7.3.4 未经允许开图传 = 取消资格 | 侦察主通道走数传；图传上电前必须报备 |
| 5 | 通则 8.5 无线电干扰申诉不受理 | 频点自己错开；不假设天空干净 |
| 6 | 通则 7.1.2 教师不得操作设备 | 一切按 4 名组员设计 |

断电/急停条款：技术要求 2.3"人工切断动力的安全开关"；细则 5.7 进场 1 分钟内当裁判演示；5.8 起飞流程要"再开启飞行器"（⇒ 开关可复位）+ 飞行中唯一人工操纵 = 紧急停止（⇒ RC6 急停拨杆）。

## 3. 上场 1 分钟流程（全程 ≤60s，不敲命令）

**提前做**：Jetson 预加载模型 → 黑帧推理自检/预热 → suspend；电池充满（>22.5V，刚触发严重保护落地的强制换电）；舵机两路地面动作测试 + 装瓶。

**上场 60 秒**：

```
放机 → 装瓶 → 按计时器 → 开机唤醒 → 报备图传电源（如用）→
当裁判演示总开关断电/复位（5.7）→ 飞手待命 → 切 GUIDED（程序启动的最终确认）→ 手动解锁
```

## 4. 上场前检查表（逐项打勾）

**机械与电气**
- [ ] 电机螺丝、桨保、限位紧固（HIT 电机飞出炸机教训）
- [ ] 电池标签 + XT60/总开关连接可靠；三级断电链路通
- [ ] 舵机两路动作测试通过（收拢 1100/释放 1600）+ 两瓶在位
- [ ] 上电后机头不动，核对锁头航向（罗盘漂移 = HIT 一机组失利疑因）

**软件与链路**
- [ ] 冷启动验证 systemd 自启（**不能 SSH 手拉**）
- [ ] `preflight_only` 只读预检：模型/标定/配置/设备四项，打印生效配置摘要核对（防 YAML 与代码脱节）
- [ ] `m1_no_vision_mode=false`、`enable_release_output=true`（实弹）、`auto_arm_on_guided=false`
- [ ] 磁盘剩余 >512MB（证据落盘会写满卡）；数传频点与邻场错开（Net ID 静默流程改，见 [04_外设链路](04_外设链路.md) §2）

**参数终检（与调试期不同处！）**
- [ ] `FS_THR_ENABLE=0`（调试期是 5=RTL）
- [ ] `RC6_OPTION=31` 急停拨杆实测可用（SWC→CH6）
- [ ] 遥控端 iA6B failsafe = **No pulses**
- [ ] 临时参数已恢复：RNGFND1_TYPE=20 / EK3_RNG_USE_HGT=4 / BRD_SAFETY_DEFLT=1
- [ ] BATT_FS_LOW_ACT=2 / CRT_ACT=1 生效；电池 22.5~23.8V 解锁窗口

**安全演示**
- [ ] 总开关断电/复位演示功能正常（细则 5.7）

## 5. 故障处置预案（原则：程序退让，人工只做紧急停止）

| 情形 | 动作 |
|---|---|
| 程序行为异常 | 飞手切出 GUIDED → 状态机立即 PILOT_OVERRIDE 停发退让 → 人工接管（Stabilize/AltHold） |
| 飞行中紧急停止 | SWC 拨 CH6 高位 → 电机停转锁死；复位 = 拨回低位 + 重新解锁 |
| 一切失控 | 反火花总开关（飞控日志完整保留，利于复盘） |
| 低电 | 自动的：21.6V RTL / 21.0V Land |
| 断数传 | FS_GCS_ENABLE=0 不动作，机载自主兜底 |

空中应急处置细节（姿态异常/炸机前兆等）见打印卡《现场操作》附录 B。

## 8. 投放舵机验收操作（台架，比赛前置）

Windows COM 直连（推荐，`servo_test.py`）：

```bash
python 02_飞控与硬件/调试工具/servo_test.py COM5 9,10        # 两路七步时序 + 逐拍回读
python 02_飞控与硬件/调试工具/servo_test.py COM5 10 loop     # A2 连续扫动（边扫边查线/量电压）
```

Jetson 路径（`fc_servo_test.sh`）等价可用；不动时 `fc_servo_diag.sh` 抓 `/mavros/rc/out` 区分"指令没到"（飞控问题）vs"舵机没电"（供电问题）。

- 前提：UBEC 6.0V 注入 A 排母线（**上电前万用表实测 6.0V，档位以表为准**——见 [02_装机接线](02_装机接线.md) §8）；电池供电（仅 USB 电调无主电）；**不解锁不转桨，拆桨纪律照守**；
- 脚本自动解会话安全锁 + SERVOx_FUNCTION=0 检查；PWM 与任务逻辑同源（1100/1600）；
- 验收：动作干脆（释放 1600µs 保持 0.7s 回仓 1100µs）、两路独立、回仓指令逐拍重试；
- 本体判据沉淀：拨舵机臂手感二分（硬=带电保持查信号/软=无电查供电轨）；温感三分（烫=极性反或堵转/凉软=没电/凉硬=有电没信号）；
- ⚠️ A2 有虚插前科（09-18）：每次上电例行连扫 2~3 轮重点盯 A2；比赛日建议评估更换插头/线材。

## 10. 自查题

1. 完赛硬门槛是什么？侦察填错一个的代价？（起飞+空投≠0+侦察对≥1+着陆+交单；错一个 −100 且可能负分）
2. 进场只有 1 分钟，靠什么做到上电即跑？（预加载+黑帧预热+suspend+systemd 自启，不能 SSH 手拉）
3. 上场参数与调试期必须不同的有哪些？（FS_THR_ENABLE 5→0 等，见 §4 参数终检）
4. 飞行中唯一允许的人工操纵是什么？（细则 5.8 紧急停止 = SWC/CH6 急停；程序异常时切出 GUIDED 由状态机退让）
5. 舵机"指令到了但不动"先查什么？（供电轨——fc_servo_diag 抓 rc/out 区分指令与供电；拨臂手感/温感判据）

## 1. 日常连接与运维基础

### 1.1 Windows 侧（飞控台架）

- 工具目录：`02_飞控与硬件/调试工具/`（pymavlink + pyserial，`pip install pymavlink pyserial`）；

### 2.2 参数体系（4.7-beta 两大特性 + 基线全文）

**① 新一代参数命名（SI 单位后缀）——写旧名会被静默忽略**（回读应答超时而非报错）：

| 旧名（资料/老固件常见） | 本固件实名 | 说明 |
|---|---|---|
| WPNAV_SPEED | `WP_SPD`（m/s） | GUIDED 速度也归它管（GUIDS_* 整组取消） |
| LAND_SPEED | `LAND_SPD_MS`（m/s） | |
| FS_GCS_ENABL | `FS_GCS_ENABLE` | |
| BATT_LOW / BATT_CRT | `BATT_LOW_VOLT` / `BATT_CRT_VOLT` | 写旧名静默失效 |
| GUIDS_ANGLE | `ATC_ANGLE_MAX` | **单位已改"度"**：写旧值 3500 触发 PreArm "must be >= 10 and <= 80"，应写 35 |

另：这版**没有任何 `COM_` 前缀参数**（`COM_RC_IN_MODE` 不存在）、**没有 SR0_\* 流送参数**、**没有 GPS2_BAUD**（GPS 口波特率跟底层串口 SERIAL4）。全参数快照 `02_飞控与硬件/调试工具/_param_dump.txt`（09-09 改动**前**的快照，对账时注意），查参数名以它为准。

**② 懒加载参数组 → 参数必须导入两遍（中间重启）**：`RNGFND1_*`、`PLND_TYPE` 等在功能开启并重启前**不存在**于参数表；反向也成立（`RNGFND1_TYPE=0` 时其子参数从表里消失，参数总数 1086→1071 是这个原因，对账遇计数差异先想到懒加载，不是丢参数）。

### 2.3 电池与解锁电压（6S 专属）

- 出厂默认 3300mAh/10.5V 是 3S 值；本机 6S 8000mAh（标称 22.2V，满电 25.2V）；
- 三级阈值：低电 21.6 → **RTL**；严重 21.0 → **Land**；解锁门槛 `BATT_ARM_VOLT=22.5`；
- **22.5 的区间推理**（为什么不设 24.5 也不设 21.8）：
  - 下限 = 低电阈值 21.6 + 悬停带载压降（6S 8000 约 0.6~1.0V）≈22.5——低于它解锁后一上负载就跌进低电区，起飞即触发失效保护；
  - 上限 ≈23.8——再高短飞落地（静止 ~23.2-23.5）无法复飞（**首版 24.5 的教训：只有近满电能解锁**）；
  - 22.5 = 标称与存储之间：存储态 22.92V 可解锁；刚触发严重保护落地的电池（静止回升 ~22.0-22.2）拒绝解锁，**强制换电**——这是设计行为不是故障；
- 压降为估算值，系留试飞时看悬停带载电压校核，必要时微调。

### 2.4 电机测试（拆桨，未解锁也能测）

```bash
python 02_飞控与硬件/调试工具/motor_test.py COM5 [输出口]
# 全测 M1→M4；python motor_test.py COM5 3 只转 M3
```

**脚本内部三道核验**（防"看着按序实际点错口"）：

1. **机架换算表**：读 FRAME_CLASS/FRAME_TYPE 查内置表取"输出口→测试序列号"映射（四轴 +/X 两种，其他机架直接拒绝）；
2. **输出口绑定**：逐个读 SERVO1~4_FUNCTION，必须 = Motor1~4(33~36)，否则拒绝盲测——`DO_MOTOR_TEST` 按"电机"寻址，绑定不对时"按序"是假象；
3. **安全开关代解**：自动发 `MAV_CMD_DO_SET_SAFETY_SWITCH_STATE`(5300) param1=1 解**会话**安全锁（`BRD_SAFETY_DEFLT` 只管开机默认，会话内状态独立）。

其他行为约定：

- ⚠️ param1 是**测试序列号不是输出口**（Quad X 序列 = 前右→后右→后左→前左，直接发 1~4 表现为"顺时针绕圈"点亮，是固件设计行为别误判接线错）——脚本内置 `OUT2SEQ={1:1,2:3,3:4,4:2}`；
- 顺序强制：升序去重；每台等满转 1s + 间隔 2.5s；中途被拒立即停；开跑前 3 秒倒计时；
- ⚠️ **只插 USB 不接电池时电机测试无效**（电调无主电）；
- 方向修正：对调该电机三根相线中任意两根（方向表见 [02_装机接线](02_装机接线.md) §5）。

### 2.5 校准（一律走 Mission Planner GUI！）

⚠️ 本 beta 对裸 `MAV_CMD_PREFLIGHT_CALIBRATION` 回 COMMAND_ACK ACCEPTED 但**静默不执行**——**校准别用裸 MAVLink**。

**① 无线电校准（RC）**——ESC 校准的前置：MP → 初始设置 → 必需硬件 → 无线电校准（前置 = PPM 链路已通）。

**② 加速度计 + 罗盘**：

1. MP 六面校准；完成后报 "requires reboot" → 重启加载生效（实测罗盘偏置落盘、姿态 roll +0.2°/pitch +0.9° 稳定）；
2. 验证：PreArm 的 Accel/Compass 告警消失；
3. 罗盘勾选：**IST8310（NEO-3 外置）勾 External 当主罗盘；RM3100（V6X 板载）取消 External**——勾反 = 板内受扰罗盘当主用 = 航向漂/EKF 拒定/炸机；改完 Reboot **必须重跑一遍校准**（改勾选的参数写入后等 5 秒再重启）；
4. ⚠️ MP 校准进度条"满了归零重来" = 拟合拒绝自动重采（转太快/磁干扰），非故障；室内钢筋环境 Z 轴偏移可能偏大（经验值 <150），解锁一致性检查过了就能用，户外重校兜底（当前挂账：首飞前必做罗盘校准）。

**③ ESC 油门行程校准**（参数法定案，免 MP 向导，推荐固化）：

1. 前置：**无桨**、无线电校准已完成、机体压稳；
2. MAVLink 写 `ESC_CALIBRATION=3`（**等 5 秒刷存储**）；
3. 拔电池**并拔 USB** → 只接电池 → 电调自动学行程：听"音乐音 + 2 滴（满行程）→ 6 滴（6S 每芯）→ 1 长音（完成）"；
4. 参数自动归零，回读确认；
5. 验证：解锁慢推油门，四电机齐转、响应一致（motor_test.py 复核）；
6. ⚠️ 校准完成后飞控自动重启一次可能**卡死 + 残留假 PreArm**（Baro not healthy / Battery failsafe）——**彻底断电复位 + 1 分钟预热一招清**，不是坏件。

### 2.6 解锁

**桌面 STABILIZE 解锁**（非位置模式，强制层豁免；✅ 已实测零拒绝）：

- 条件全绿：电压 ≥22.5V、加速计 ✅、罗盘 ✅、RC 健康、电机参数 ✅（MOT_SPIN 组）；
- 操作：左摇杆右下 2s 解锁（电机怠速），左下 2s 上锁；
- 排障（PreArm 拒绝逐条清；**抓拒绝原文要听满整个窗口**——COMMAND_ACK 比 STATUSTEXT 先到，只抓 ack 会误判）：

| 拒绝原文 | 根因 → 处置 |
|---|---|
| `Battery below min arming voltage` | 电压 <22.5V → 充电（存储态 22.9V 可解锁；刚触发严重保护落地的电池强制换电） |
| `Accels/Compass calibrated requires reboot` | 校准后没重启 → 断电重启 |
| `MOT_SPIN_ARM > MOT_SPIN_MIN` | 怠速参数孤儿值 → 成组写回 0.15/0.13 |
| `Motors Emergency Stopped` | 急停拨杆在触发位 → CH6 拨回低位 + 重新解锁 |
| `Compass not calibrated` | 重校罗盘（§2.5②） |
| `RC not found` / Radio failsafe | 接收机链路断 → 查 PPM 接线（[02_装机接线](02_装机接线.md) §6） |
| `Arm: Need Position Estimate` | **GUIDED 专属强制层**，桌面绕不过（见下） |

**GUIDED 任务链 = 另一回事，硬依赖位置源**：

- 4.7 固件强制层：`Arm: Need Position Estimate`（mandatory 检查，ARMING_SKIPCHK=-1 也跳不过）；
- 状态机路径同样卡 `WAIT_NAV_STABLE`：真机无 GPS 时 mavros local_position/odom 不出流（SITL 有仿真 GPS 所以能过）；
- 结论：**GPS 户外出星之前，GUIDED 全流程不可能真机跑**。别在桌面跟这条死磕。

### 2.7 遥控器端配置（FS-i6）

- 通道规划：CH1~4 摇杆；**CH5 = 飞行模式**（SWA 三段）；**CH6 = 急停**（SWC 两段，RC6_OPTION=31）；
- 开关分配在 AUX 菜单；**开关测试要做单开关单测**（混测+统计窗口曾把 SwA 余动作误判成 SwC）；
- ⚠️ **failsafe 必须改 No pulses**（RX SETUP → FAILSAFE；出厂"保持"会让飞控察觉不到断链）——挂账待做；
- 急停语义：SwC 高位(>1800) = 电机停转锁死；解除 = 拨回低位 + 重新解锁。

### 2.8 失效保护配置总表

| 项 | 现值 | 说明 |
|---|---|---|
| FS_GCS_ENABLE | 0 | 数传断链不动作（自主兜底） |
| FS_THR_ENABLE | 5(RTL) | **调试期安全值；上场前必须改 0**（改 0 后断链完全静默，务必赛前核对） |
| BATT_FS_LOW_ACT | 2(RTL) | 低电 21.6V 返航 |
| BATT_FS_CRT_ACT | 1(Land) | 严重低电 21.0V 降落 |
| RC6_OPTION | 31 | CH6 急停 |

## 3. 自查题

1. 刷机后怎么确认固件版本没刷错？（心跳 MAV_TYPE_QUADROTOR + flight_custom_version=dbe79216 与存档一致）
2. 参数导入后 verify_params 报 5 项"不存在"，是丢参数吗？（懒加载反向：TYPE=0 时子参数从表里消失，预期行为）
3. 解锁门槛为什么是 22.5V 不是 24.5 也不是 21.8？（24.5 只有近满电能解锁；21.8 解锁后带载即跌入低电区）
4. 电机测试"顺时针绕圈"点亮是接线错吗？（不是——DO_MOTOR_TEST param1 是测试序列号，脚本已换算）
5. ESC 校准后飞控卡死怎么办？（断电复位一招清，不是坏件）
6. 桌面能把 GUIDED 任务模式解锁跑起来吗？（不能——强制层 Need Position Estimate，等 GPS 户外出星）
7. PLND_TYPE 应该是多少？（1=CompanionComputer——09-14 勘误后口径；0=Never/2=IRLOCK 都不对）

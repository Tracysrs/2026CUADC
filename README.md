# 无人机国赛 · CUADC 2026

2026 中国大学生飞行器设计创新大赛（CUADC）· **多旋翼侦察与救援项目**。
**方案唯一权威版本（SSOT）：[01_设计/总体方案与执行计划.md](01_设计/总体方案与执行计划.md)**——改方案只改那一份，其余文档一律不改。

## 快速上手

- 要改方案 → 只改 `01_设计/总体方案与执行计划.md`，其余文档一律不改。
- 要训练模型 → 看 `02_数据与训练/v2训练流水线/AutoDL租卡训练指南v2.md`。
- 要连飞控 → 先看 `03_工具/飞控调试/README.md`（断开 Mission Planner、参数导入两遍）。
- 要改代码 / 跑仿真 → 看 `10_机载代码/README.md`（每版先过 SITL 再上真机）。
- 要了解项目进展 → 看最新的 `09_工作日志/*.md`。

### 2.2 三条流

- **数据流（感知→决策）**：相机（取帧时刻戳）→ 三个感知节点（推理+门控+融合）→ 契约话题（PoseArray 机体系 / classification / h_circle）→ 状态机（odom 历史插值夹逼还原取帧瞬间位姿→世界系筒位地图/判读结论/降落目标）。判读结论另走 STATUSTEXT→数传→MP 消息栏给组员填单。
- **控制流（决策→执行）**：状态机 20Hz tick → MAVROS（GUIDED setpoint / CommandTOL / DO_SET_SERVO）→ TELEM3 MAVLink2@921600 → FC 姿态/位置环（400Hz 级）→ 混控 → 4×电调 200Hz PWM → 电机；投放为 DO_SET_SERVO 直发 SERVO9/10（FUNCTION=0，不受混控影响）；精准降落为 LANDING_TARGET→PLND 模块在 LAND 态自动接管。
- **反馈流（机体→传感→决策/飞控）**：IMU/气压/罗盘（FC 内环自闭环）；CAN1 DroneCAN GPS（NEO3 Pro）+ PMU 电压电流→EKF/失效保护；odom/ATTITUDE/GLOBAL_POSITION 由 FC 回流 Jetson（状态机插值基准+安全监控五路心跳之一）；相机下视图像闭环（找筒/判读/H 圆）；RC PPM 与 STATUSTEXT 为两条人工观察/干预通道。

### 5.3 状态机与模式切换（18 态 @20Hz，SSOT §5.1）

`WAIT_FCU → WAIT_NAV_STABLE → LOCK_FRAME（航向 2s 内变 ≤2°，超 30s 判罗盘故障）→ PRESTREAM（预发 setpoint 1.5s）→ WAIT_GUIDED（飞手切 GUIDED=最终确认）→ WAIT_ARM → TAKEOFF（3m）→ SEARCH（2m 蛇形 6 带）→ ALIGN（粗 0.15→精 0.08m，稳定 0.8s，超时 12s 弃桶）→ RELEASE（×2，八门控连续 2.3s，单发 0.7s 回仓）→ RECON_CLIMB → RECON_SURVEY（3m 蛇形 3 带+拍照握手 1s 兜底）→ RETURN_CLIMB → RETURN_HOME（3m）→ LAND（≤0.30m+速度门限+稳定 1.5s）→ DISARM（独立态=桨停）→ DONE`；旁路 `PILOT_OVERRIDE`（切走 GUIDED 即退让）/`ABORT`（致命故障 fail_and_return）。

模式切换约定：任务全程 GUIDED；飞手可随时切走（程序不抢权）；**解锁前模式门禁**与急停链按 03 册 §2.7/§2.8（**2026-10-04 拍板：SWC 低=Stabilize / 中=空（预留）/ 高=Guided（任务启动），FLTMODE1=0 / FLTMODE3=0 / FLTMODE6=4；RTL 不在开关上，由 failsafe 自动 RTL 承担**）。

### 6.5 L3 外场低空用例

1. **真机 M1 全自主首飞**（里程碑欠账）：起飞→预设航线→降落，起飞+着陆分到手，用时对预算。
2. **罗盘/GPS 实环境**：户外校准后 LOCK_FRAME；GPS ≥8 星/HDOP<1.5 门禁实测；（若 X20P 复装）四组 RTK 验收+Fix 率，达标才转主用，**任务流程任何时不依赖 Fixed**。
3. **制动实测**：提速档位 4→6m/s 逐级，实测制动距离 >1.2× 预算即停级（SSOT §5.5）。
4. **时间预算实测**：全流程分段计时 vs §5.5 预算表，超差段定位。
5. **相机曝光复核**（10-01 豁免条件）：侦察段判读产出/影子帧运动模糊对确认率影响实测，不达标→重启换相机评估。
6. **试投标定**：每载荷每高度 ≥3 次真实试投→`最终偏置=静态偏置+落点偏差中位数`+MAD；累计 ≥20 次统计 **CEP<5cm**（M3 验收线，冲 15cm 筒前提）。

### 6.6 L4 全任务彩排用例

1. **上场 60 秒流程**（§七.8 检查单）全程 ≤60s，连续 3 次无疏漏（M6 线）。
2. **两轮制全模拟**：装双瓶真投+计时器+判读填单+停表；判据 = 零判罚 + 完赛五要素全过 + 模拟分：保底线（~330）×2 必达、冲奖线（1250+）至少 1 次。
3. **判读填单演练**：STATUSTEXT 回传组员填单 vs 证据 JSONL 事后对账，错填=0（拒识策略实链验证）。
4. **应急演练**：场上故障处置表（断流/丢检/丢星/低压/急停高度两条铁律）抽考。

### 8.2 安全预案（现场速用）

- **三级切断**：①机械总开关（断电，裁判演示件）②RC6 急停（不断电、日志完整，飞行中唯一合规人工操纵，**只许 <0.5m 贴地用**）③自动失效保护（21.6V RTL/21.0V Land/RC 失效 RTL/EKF Land）。
- **failsafe-RTL 触发后**：优先让 RTL 执行完，**禁止**在 RTL 爬升/巡航高度按急停（161 摔机直接根因）。
- **台上任何异常**：先切 Stabilize/PosHold 人工接管（=PILOT_OVERRIDE，程序自动退让）再处置；禁盲目急停。
- **地面纪律**：连 FC 先断 MP；拆桨做电机/舵机测试；参数两遍导入+写后等 5s+重启。

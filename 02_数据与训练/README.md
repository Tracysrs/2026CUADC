# 02_数据与训练 · 视觉模型的数据与训练

检测/分类模型的**数据集资产与训练流水线**。训练验收标准与版本管理规则见 SSOT《总体方案与执行计划》§8。

## 内容

| 项 | 内容 | 说明 |
|---|---|---|
| `train/` | 实拍原始数据（约 246MB） | 无人机俯拍标识桶原片，已剔除无关截图 |
| `real_data/` + `real_data.zip` | 切分好的训练集（约 244MB） | 按视频片段切分 train/val（防连续帧泄漏），`real_data.zip` 为交付队友用的打包版 |
| `build_real_data.py` | 数据集构建脚本 | SRC/DST 跟随脚本所在目录，整个目录挪走也能跑 |
| `v2训练流水线/` | 云端训练全套（约 547MB） | `AutoDL租卡训练指南v2.md`（操作手册）+ `run_v2_training.sh`（一键训练，内含 v1 自动兜底）+ `hazard_labels_v2_11class*`（v1 合成数据包 2220 张/11 类） |

## 怎么用

1. 训练 → 看 `v2训练流水线/AutoDL租卡训练指南v2.md`（租卡 → 上传 → 一键脚本 → 取结果）；
2. 新一批数据 → 沿用 `build_real_data.py` 的切分逻辑构建；
3. 验收判读表 → SSOT §8.2：逐类 mAP50≥0.90、白底三类≥0.85、漏检<5%。

## 注意

- 数据集版本命名：`hazard_synth_v1` → `hazard_mix_v2` → v3…，数据快照与权重同名存档；
- **现场实拍验证集必须独立保留**（模拟比赛当天光照），不并入训练集；
- 本目录体量大（约 1.3GB），**根仓库不入库**，只入库 `build_real_data.py` 与训练指南/脚本（见根 `.gitignore`）。

# 01_视觉感知

视觉线全部产出：算法设计 + 数据与训练。

| 文件/目录 | 说明 |
|---|---|
| `视觉算法设计.md` | 视觉三任务（危化判读/找筒/H 圆）算法详细设计（登记于 SSOT 文档地图，2026-09-13） |
| `数据与训练/README.md` | 数据与训练目录索引 |

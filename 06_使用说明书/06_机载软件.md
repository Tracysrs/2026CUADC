## 3. MAVROS 链路详解（"连上了但没数据"的完整答案）

### 3.1 三个必要条件（缺一没数据）

1. **ArduPilot 见到 GCS 心跳才开始流送遥测**，mavros 不冒充 GCS → mavros 开 `gcs_url:=tcp-l://0.0.0.0:14550` 桥 + `gcs_pump.py` 心跳泵（**必须先发后收**）；
2. **4.7-beta 没有 SR0_\* 流送参数**（写了被静默忽略）→ MAVROS `set_message_interval` 逐条订阅，7 条消息：

| message_id | 消息 | 内容 |
|---|---|---|
| 1 | SYS_STATUS | 传感器健康/电池 |
| 30 | ATTITUDE | 姿态 |
| 32 | LOCAL_POSITION_NED | 本地位移/速度（odom 源） |
| 33 | GLOBAL_POSITION_INT | 全球位置/相对高度 |
| 74 | VFR_HUD | HUD 汇总 |
| 147 | BATTERY_STATUS | 电池详情 |
| 245 | EXTENDED_SYS_STATE | 起降状态 |

执行后 odom 出流 ~4.7Hz，状态机立刻过导航门禁；
3. 多网卡（WiFi+RNDIS）组播跑错口 → `export ROS_LOCALHOST_ONLY=1`。

### 3.2 一键验证

```bash
bash 02_飞控与硬件/调试工具/fc_dryrun.sh [秒数]      # 链路验证 + 状态机干跑（无桨不解锁）
# 手动形态：
ros2 launch mavros apm.launch fcu_url:=/dev/cuadc-fc:115200 gcs_url:=tcp-l://0.0.0.0:14550
python3 scripts/gcs_pump.py                    # 另开终端：心跳泵
```

### 3.3 MAVROS 2.14 版本特性（脚本已固化）

- 参数列表同步约 17s（mavros.log 出现 `parameters list received`），完成前 **set 静默失败、读回陈旧值**；
- `/mavros/param/set` 是 `mavros_msgs/srv/ParamSetV2`（`force_set` + `value.type=2`）；读参数用 `/mavros/param/get_parameters`（字段名 `names`），**没有** `/mavros/param/get`；
- DDS 挂死先 `ros2 daemon stop` 重置；
- **判断连接别用 `ros2 topic echo --once`**（起动高压期 DDS 发现慢，假阴性）——以任务节点通过 WAIT_FCU 为准，或 pymavlink 直探。

### 4.2 设计约定

- **逻辑规范与 ROS 解耦**：drop_logic.py 不 import ROS、不做坐标变换——可离线单测/蒙特卡洛；C++ 消费端逐函数镜像回归；
- **契约先行**：消息在写代码前定死（接口契约.md），双哨兵 + fail-closed；
- **参数三方一致**：代码声明 = 代码加载 = YAML；改节点名必须同步 YAML 顶层键。

### 4.3 与参考代码（HIT 公开版）的关键差异

| 点 | 公开版 | 本实现 | 依据 |
|---|---|---|---|
| 坐标系锁定 | 藏在导航就绪态里 | `LOCK_FRAME` 独立态，航向 2s 内变 ≤2° | 罗盘漂移为 HIT 失利根因 |
| 搜索后行为 | 演示参数直接进对准 | 正式模式 fail-closed；`m1_no_vision_mode=true` 才飞预设航线演练 | M1 验收需要无视觉全流程 |
| 投放决策 | 演示级 | 锁定五步/八门控/DropSequencer 完整实现 + 双镜像测试 | SSOT §5.2 |

## 6. 红线（03_机载软件/README 同款）

1. **每一版先过 SITL 再上真机**；真机首测拆桨、安全员、人工接管手段；
2. `auto_arm_on_guided` 默认 false，解锁权在飞手；
3. 正式训练/比赛 `m1_no_vision_mode` 必须为 false（演练模式仅用于无视觉排查）；
4. M2 真感知实现后，`fake_perception_node` 仅用于联调。

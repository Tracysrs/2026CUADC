## 怎么用

1. 现行训练路线 → SSOT §8.2（COCO 直训；deliver_v2 即产物范式）；
2. 新一批数据 → 沿用 `build_real_data.py` 的切分逻辑构建（先确认标签是附件11 实表类别号）；
3. 验收判读表 → SSOT §8.2：逐类 mAP50≥0.90（逐类无豁免）、漏检<5%。

## 注意

- 数据集版本命名：`hazard_hgd_10cls_v2`（当前）→ v3…，数据快照与权重同名存档；
- **现场实拍验证集必须独立保留**（模拟比赛当天光照），不并入训练集；
- 本目录体量大（约 1.3GB），**根仓库不入库**，只入库 `build_real_data.py` 与训练指南/脚本（见根 `.gitignore`）。

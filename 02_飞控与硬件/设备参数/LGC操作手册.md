# LGC（LGroundControl）操作手册

> 2026-09-23 立册。LGC 是雷迅创新基于 QGroundControl 二次开发的中文地面站，是 **X20P 基站配置的唯一工具**（收敛精度/收敛时间只有它能配；QGC 不支持 X20P，MP 只能做 RTK Inject 注入配不了收敛项）。
> 下载：https://dl.cuav.net/software/lgc.html （Windows 安装包，进程名 `LGroundControl.exe`）。
> 依据：CUAV 官方 X20P 使用指南（doc.cuav.net，2026-09-23 查）+ 本仓 09-22/09-23 实测笔记。标注「待实机核」的条目为官方文档未覆盖、首次操作时回填。

## 0. 先记住三条坑

1. **LGC 会独占串口**：开 LGC 连哪个口，那个口就不能同时被 Mission Planner / 本仓调试脚本（check_can.py / rtk_inject.py 等）使用。今天（09-23）早上它后台占着 COM17 导致脚本连不上飞控，就是这个原因。开 LGC 前想清楚要占哪个口。
2. **连模块还是连飞控是两回事**：USB 直连 X20P 模块 = 配基站/看模块状态；连飞控 COM 口 = 整机 MAVLink 配置。别混。
3. **版本要新**：09-22 旧版 LGC 的「定位设置」向导未收录 X20P（改率无入口）。装最新版；向导里找不到 X20P 就直接走参数表。

## 1. 端口速查（当前台架状态）

| 设备 | 口 | 说明 |
| --- | --- | --- |
| 基站 X20P（USB 常连电脑） | COM18 | 「USB 串行设备」，重插后口号会漂，认描述不认号 |
| 流动站 X20P（罗盘检查临时连） | COM19 | 同上；它同时在 FC 的 CAN1 上，LGC 占 COM19 不影响 CAN 链路 |
| 飞控 V6X | COM17 | 「ArduPilot MAVLink」——LGC 连这个 = 整机配置，会顶掉调试脚本 |

## 2. 基站配置（核心场景，外场必用）

**前置**：基站 X20P 用 USB 连电脑；**长按 MODE 按钮切到基站模式**（MODE LED 绿色常亮；绿闪=流动站，短按无效须长按）。

**流程**（官方口径）：

1. 运行 LGC，连接基站的 COM 口。
2. 界面出现 **RTK 卫星图标** = 已识别到 X20P 基准站。
3. RTK 字样**红色** = 收敛中（survey-in 观测定位）。
4. 默认收敛精度 **3.0m / 最短 30s**；收敛精度可在 RTK 界面自设（精度越高等越久；默认档在流动端解算后即可 <1cm。HIT 教训：2.49m 勉强过线，正式场建议收紧到 1m 档并记录实际收敛值）。
5. RTK 字样变**白色**、状态显示 **「RTCM 报送」** = 基站配置完成，开始向外发差分。
6. 从 LGC 读出收敛坐标 **GNSS_BASE_LAT / LON / H_CM**，填入基站卡（F-04 模板，12_记录模板.md §4）。
7. **基站全程禁动**。

**坐标固化（可选）**：同一训练场反复用同一架设位时，可把收敛坐标固化为固定 LLH（模块参数 GNSS_BASE_MODE=2，配 GNSS_BASE_LAT/LON/H_CM；入口在 LGC 参数表或定位设置向导——**待实机核**，09-22 版向导未收录 X20P 时只能走参数表）。固化后同点位复飞免重收敛，换场地必须重新 survey-in。

## 3. 流动站模式确认 / 罗盘检查（当前任务）

1. 流动站 USB 连电脑（COM19），MODE LED **绿色闪烁** = 流动站模式（不是就长按 MODE 切换）。
2. LGC 连 COM19。
3. **罗盘**：官方文档未写 LGC 有罗盘页面——依次找「车辆设置→传感器→罗盘」类页面（QGC 血统会有）和 RTK 页面，看有无实时读数（转动模块数值应变）。找不到罗盘页不等于罗盘坏，**最终判据仍是 FC 侧 COMPASS_DEV_ID3 是否出现**。
4. 顺手确认定位状态页有卫星/坐标显示（室内 0 星属正常，勿误判坏件——04 册 §4.1）。

## 4. 与本仓工具链的分工

| 要做什么 | 用什么 |
| --- | --- |
| 基站模式 / 收敛精度 / 坐标固化 / 读收敛坐标 | **LGC**（唯一工具） |
| RTCM 注入流动站 | MP 的 RTK/GPS Inject，或本仓 `rtk_inject.py`（等效，且不占飞控口给 MP） |
| 流动站接飞控参数 | 已全落机：GPS1_TYPE=9、CAN_P1_DRIVER=1、GPS_AUTO_CONFIG=2（官方 CAN 口径） |
| 模块内部参数（GNSS_RATE_MS 等） | LGC 参数表（UBX 直配会被固件 NAK，u-center/脚本不可行） |
| 通联/状态检测 | 本仓 check_can.py / check_rng.py / rtk_inject.py |

## 6. 无 LGC 工作流（2026-09-23 拍板：日常不装 LGC 也能全链跑通）

基站用**出厂默认收敛档（3m/30s）**：长按 MODE 绿常亮 → 自动 survey-in → **MP 的 RTK/GPS Inject 页读收敛状态与坐标**（09-23 实测口径：NAV-SVIN 精确数字以 MP Inject 页为准）填基站卡 → 禁动。罗盘判定权在 FC 侧 `COMPASS_DEV_ID3`，与 LGC 无关。

**放弃的三项（值得装回 LGC 的时机）**：

| 放弃项 | 代价 | 装回时机 |
| --- | --- | --- |
| 收敛精度收紧（1m 档） | 出厂 3m 档有「勉强过线」风险（HIT 教训 2.49m） | 正式比赛场收敛慢/Fix 不稳时 |
| 坐标固化（固定 LLH） | 每次架设重跑 survey-in，多花 2~3 分钟 | 同一场地高频复用且嫌重收敛烦时 |
| 模块改率（GNSS_RATE_MS） | 25Hz 验证持续挂起（飞行维持 5Hz 不受影响） | 04 册 §3 一定要验 25Hz 吞吐时 |

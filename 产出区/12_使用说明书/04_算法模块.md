## 1. 白筒检测（双通道 + 时序后处理）

**输入**：下视单目 640×640；**输出**：机体系筒位 + 直径估计 + 置信度。

| 通道 | 实现 | 定位 |
|---|---|---|
| 主 | YOLOv8n-seg，TensorRT FP16，imgsz=640 | Orin 实测 52.8FPS（验收 ≥25） |
| 副 | LAB 的 L 通道高 + A/B 近中性 → 阈值 + 形态学 → `cv2.fitEllipse` | 光照异常兜底，与主通道 IoU 匹配降置信 |

**后处理四件**（每件对应一次实战教训）：

1. **时序一致性**：连续 5 帧、位置 std < 阈值才确认，取中位数（防单帧抖动误检）；
2. **同帧去重**：双框中心距 <2cm 合并——HIT 区赛"同桶拆两目标、两瓶投一点"；
3. **独立性门控**：两筒水平距离 ≥0.20m **且**直径差 ≥0.025m 才算不同目标——参数必须真正参与判断（HIT 的直径判据写了没生效）；
4. **直径物理先验**：像素直径反算物理直径必须落 [0.08, 0.35]m 且能对号 15/20/25cm（容差 0.035m），否则拒检——免费一致性校验，还能反推筒号辅助投放顺序。

## 2. 单目坐标解算

> 2026-09-13 口径修正：主测距 = **飞控相对高度**（`h_m = odom_z − plane_z`，
> 桶口 plane_z=0.30m / H 圆 0m），像素椭圆只出**横向偏移与直径**。下式的
> `Z = f·H/h_px`（H=筒高）在正下视画面中心区域无定义（看不到筒侧壁），仅边缘
> 斜视角可用，降级为 sanity——详见《01_设计/视觉算法设计.md》§3.3。
> 已知筒高 H=0.30m、内参 (fx, fy, cx, cy)、像素高 h_px、中心 (u, v)：

```
距离   Z = f_px × H / h_px          # f_px ≈ (fx+fy)/2
横向   dx = (u − cx)·Z / fx
纵向   dy = (v − cy)·Z / fy
世界系 p_world = body_to_local_at(t_frame) ⊕ p_body     # §4 的时间同步插值
```

推导直觉：同焦距下像素高度与真实高度成正比——`Z/H = f/h_px`，移项即得。横向同理：偏心 u−cx 越大、离得越远，投影偏移越大。

要点：

- **对准平面要减桶高**：瞄准的是桶口平面，`alignment_z = 目标参考高 − 0.30m`（HIT 标定工具里的坑）；
- 高度只用飞控相对高度（TFmini 4m 以下辅助），不用气压；
- **起飞前锁航向**（整个任务不转机头）+ 起飞前读一次 odom 存**任务原点**（EKF 原点 ≠ 起飞点，HIT 翻车两个月）；
- 罗盘航向换算：`yaw_ENU = 90° − compass_hdg`；本地系 ENU，机体系 FLU（x 前 y 左 z 上）。

## 3. 坐标系三件套（全项目最大坑，HIT 翻车两个月）

1. **任务原点**：起飞前记录 odom（EKF origin ≠ 起飞点）；
2. **航向转换**：`yaw_ENU = 90° − compass`（ENU 本地系 ↔ 罗盘航向）；
3. **锁航向**：整个任务不转机头；状态机 `LOCK_FRAME` 独立态强制把关（航向 2s 内变 ≤2° 才锁任务坐标系，超时判罗盘故障）。

## 4. 时间同步与延迟补偿（P0.4，已验收）

**为什么必须做（量级论证）**：搜索段 2m/s × 感知管线延迟 100ms = **20cm** 系统性位置误差 > 0.10m 对准门限——不补偿则筒位地图整体滞后，怎么调门限都投不中。

**设计核心**：戳"取帧时刻"，插值在状态机侧。

```
感知端：图像到手那一刻立刻记 stamp（不是发布时刻！），随消息发出
状态机：收到视觉帧 → 在 odom 历史缓冲里找包围 t 的两帧 → 线性插值位置 +
        最短角差插值航向 → 得到"取帧瞬间"的飞机位姿 → 机体系目标旋转平移到世界系
```

odom 以 30~100Hz 持续到达，视觉帧只是"过去某瞬间的快照"——用历史 odom 回放取帧瞬间位姿，而不是拿"当前位姿"近似。

**消费端实现**（摘自 `mission_node.cpp`，三种拒绝情况一目了然）：

```cpp
std::optional<OdomSample> interpolate_odom(const rclcpp::Time & t) const {
  if (odom_history_.empty()) return std::nullopt;
  const OdomSample & newest = odom_history_.back();
  const OdomSample & oldest = odom_history_.front();
  if ((t - newest.stamp).seconds() > odom_future_tol_s_) return std::nullopt; // 未来戳
  if ((newest.stamp - t).seconds() > perception_max_delay_s_) return std::nullopt; // 帧太旧
  if (t >= newest.stamp) return newest;   // 夹逼上界（延迟小于一拍）
  if (t <= oldest.stamp) return oldest;   // 夹逼下界
  for (auto it = odom_history_.begin(); it + 1 != odom_history_.end(); ++it) {
    const OdomSample & a = *it;  const OdomSample & b = *(it + 1);
    if (t >= a.stamp && t <= b.stamp) {
      const double gap = (b.stamp - a.stamp).seconds();
      if (gap > odom_interp_max_gap_s_) return std::nullopt;  // 断流段内不插值
      const double r = (t - a.stamp).seconds() / std::max(1e-6, gap);
      const double dyaw = normalize_angle(b.yaw - a.yaw);     // 最短角差插值
      return OdomSample{ t,
        { a.x + r*(b.x-a.x), a.y + r*(b.y-a.y), a.z + r*(b.z-a.z) },
        normalize_angle(a.yaw + r*dyaw) };
    }
  }
  return std::nullopt;
}
```

| 参数 | 默认 | 语义 |

## 6. 任务状态机（18 态 + 2 旁路）

**状态枚举**（摘自 `mission_node.cpp`，注释即设计依据）：

```cpp
enum class State {
  // ---- 准备阶段（地面）----
  WAIT_FCU,         // 等飞控连接（MAVROS ↔ Pixhawk 握手）
  WAIT_NAV_STABLE,  // 等定位 + 罗盘可用（真机无 GPS 时永远停这里——设计行为）
  LOCK_FRAME,       // 锁任务坐标系：航向 2s 内变 ≤2° 才放行（防罗盘漂移）
  PRESTREAM,        // 起飞点预发 setpoint 1.5s（切 GUIDED 前必须已有目标流）
  WAIT_GUIDED,      // 等飞手切 GUIDED（= 飞手最终确认）
  WAIT_ARM,         // 等解锁（默认飞手手动；auto_arm_on_guided 才自动）
  // ---- 任务主线 ----
  TAKEOFF,          // CommandTOL 起飞，0.9×目标高后切 setpoint
  SEARCH,           // 2.0m 蛇形；M1 演练=飞预设航线，正式=等感知锁定
  ALIGN, RELEASE,   // 对准与投放（M3，fail-closed）
  // ---- 侦察段 ----
  RECON_CLIMB, RECON_SURVEY,   // 蛇形 6 航点 + 每点拍照握手（1s 超时兜底）
  // ---- 返航与收尾 ----
  RETURN_CLIMB, RETURN_HOME,
  LAND,             // 落地判定 ≤0.30m + 速度门限 + 稳定 1.5s
  DISARM,           // 独立态：确认落地后自动上锁（规则 6.1.4 桨停转才有着陆分）
  DONE,
  // ---- 旁路 ----
  PILOT_OVERRIDE,   // 飞手切走 GUIDED：程序立即退让并退出

};
```

设计要点：

- **飞手切 GUIDED 才启动 + 程序绝不与飞手抢权**（HIT 全版本铁律）；`auto_arm_on_guided=false`，解锁权在飞手；
- LOCK_FRAME 独立成态：防罗盘漂移（HIT 一机组失利疑因的防线）；
- DISARM 独立成态：规则要求"桨停转才有着陆分"；
- 速度基线：转场 4.0 / 搜索 2.0 / 侦察 3.0 / 进近 0.7 / 释放定位 0.25 m/s；航点接受半径 0.40m；任务总超时 240s；
- `flight_gate_ok()` 每飞行态必检；odom 断流 >1s 看门狗；分级失败 `fail` / `fail_and_return()`（先返航再降）；
- 航线生成：弓字形搜索带（`smoothstep` 时间插值平滑）+ 侦察 6 航点，全部参数化（§14 场地几何组）。

**SITL 实测耗时**（zd550）：TAKEOFF ~7s / SEARCH ~21s / RECON ~20s / LAND ~18s / 全任务 82s。

### 7.1 SEARCH 段：BucketMap（航迹维护 + 锁定五步）

**喂帧与关联**（EMA + 直径中位窗）：

```python
def update(self, x, y, diameter, t) -> str:
    if not (self.p.diameter_min_m <= diameter <= self.p.diameter_max_m):
        return 'rejected_diameter'      # 物理先验：免费一致性校验，直接拒
    best, best_d = None, self.p.assoc_gate_m            # 关联门 0.50m（< 最小筒间距）
    for tr in self.tracks:
        d = math.hypot(tr.x - x, tr.y - y)
        if d <= best_d: best_d, best = d, tr
    if best is None:                    # 新航迹
        ...
    a = self.p.ema_alpha                # α=0.25
    best.x = (1 - a) * best.x + a * x   # 位置 EMA 平滑
    best.diam_samples.append(diameter)  # 直径中位窗 9（抗单帧量错）
    best.diameter = median_of(best.diam_samples)
    best.confirms += 1
    return 'associated'
```

**独立性强制合并**（HIT"两瓶投一点"的直接防线——判据在这里**真实参与删除**，不是写在注释里）：

```python
def enforce_independence(self, t) -> int:
    changed, merges = True, 0
    while changed:                       # 反复合并直到稳定（合并可能产生新的相近对）
        trs = self.confirmed(t)
        for i, j 两两组合:
            dist  = hypot(a.x-b.x, a.y-b.y)
            ddiff = abs(a.diameter - b.diameter)
            if dist < 0.20 or ddiff < 0.025:      # 任一条件即判同一筒
                keep, drop = 确认数多者, 少者
                self.tracks.remove(drop); merges += 1; changed = True
    return merges
```

**锁定（五步⑤：排名稳定才冻结）**：

```python
def try_lock(self, t, degraded=False) -> LockResult:
    self.enforce_independence(t)
    trs = [tr for tr in self.confirmed(t) if not self.is_blacklisted(tr.x, tr.y, t)]
    # 直径对号 15/20/25cm（容差 0.035）→ classified / unknown 分组
    need = 2 if degraded else 3          # 降级模式"2 筒 + 1 未知"
    if len(classified) < need: return LockResult(False, ...)
    if not degraded and unknown: unknown = []   # 正式模式：未知筒不入选（宁缺勿错）
    classified.sort(key=lambda tc: (tc[1], tc[0].diameter))   # 直径类升序
    signature = tuple(tr.tid for tr, _ in ordered)
    if signature != self._rank_signature:       # 排名变了 → 重新计时
        self._rank_signature, self._rank_since = signature, t
        return LockResult(False, 'rank_changed')
    if t - self._rank_since < self.p.rank_stable_s:   # 0.8s 内稳定才放行
        return LockResult(False, 'rank_not_stable')
    return LockResult(True, ..., targets=[FrozenTarget(...) for ...])
```

`FrozenTarget` 结构是"冻结/活动"双轨：`frozen_x/y/diameter` 锁死后**绝不被改写**（ALIGN 段瞄准参考），`working_x/y` 是活动估计（EMA 更新，可被重捕获刷新）。

**拉黑**：已投/已弃筒按位置（0.25m 半径）+ 时间（120s 窗）拉黑，`try_lock` 直接跳过——绝不回锁已投筒。

### 7.2 ALIGN 段：TargetTracker（活动估计 + 反盲投）

```python
def assess(self, t) -> str:
    """'ok'=新鲜可投；'reacquiring'=丢视觉、重捕获窗口内（禁投）；
    'abandon'=重捕获机会用完/窗口耗尽 → 弃桶。"""
    lost = self.vision_age(t) > self.p.fresh_window_s        # 0.5s 新鲜度
    if not lost: return 'ok'
    if self.target.reacquires_used >= self.p.max_reacquires: return 'abandon'  # 只有 1 次机会
    if self.target.lost_since is None: self.target.lost_since = t
    if t - self.target.lost_since > self.p.reacquire_window_s:      # 2s 窗口耗尽
        self.target.reacquires_used = self.p.max_reacquires
        return 'abandon'
    return 'reacquiring'
```

重捕获关联门：位置 0.40m **且**直径差 ≤0.06m（双门防串到别的筒）。这是"丢视觉禁止按冻结坐标盲投"的代码化：目标不新鲜就进不了八门控（见下 target_age）。

### 7.3 RELEASE 段：ReleaseGate（八门控状态机）

**弹道前移**（悬停时 ≈0，保留作 sanity——速度门限失守时的第二道闸）：

```python
def ballistic_lead(vx, vy, height_m, g=9.81):
    t_fall = math.sqrt(2.0 * max(0.0, height_m) / g)
    return vx * t_fall, vy * t_fall        # Δ = v·√(2h/g)
```

**八门控评估**（`_instant` 逐项检查 + `feed` 状态推进）：

```python
def _instant(self, s) -> (bool, str):
    if not all(isfinite):        return False, 'non_finite'
    if s.target_age_s > 0.5:     return False, 'target_stale'   # 反盲投核心防线
    if s.horiz_err_m > 0.10:     return False, 'horizontal_error'
    if abs(s.vert_err_m) > 0.10: return False, 'vertical_error'
    if s.hspeed_m_s > 0.08:      return False, 'horizontal_speed'
    if abs(s.vspeed_m_s) > 0.05: return False, 'vertical_speed'
    if s.tilt_deg > 5.0:         return False, 'tilt'
    if s.yaw_err_deg > 5.0:      return False, 'yaw_error'
    if hypot(*ballistic_lead(...)) > 0.15: return False, 'lead_excess'
    return True, 'ok'

def feed(self, s):   # 每拍一次；'fire' 只出现一次（幂等）
    ok, reason = self._instant(s)
    if not ok:
        self.pass_started = None                      # 任一违约清零两个计时器
        if s.t - self.entered_t > 6.0: return 'abort', f'timeout_last_reason={reason}'
        return 'idle', reason
    held = s.t - self.pass_started
    if held >= 0.8 + 1.5: return 'fire', 'gates_satisfied'   # 稳定 0.8 + 保持 1.5 = 连续 2.3s
    if s.t - self.entered_t > 6.0: return 'abort', 'timeout'
    return 'holding', f'held={held:.2f}s'
```

### 7.4 DropSequencer（单发舵机）与瞄准点

```python
class DropSequencer:
    """IDLE →（fire）RELEASED →（hold 0.7s）STOWED。fire() 二次调用返回 False——
    双发保护是硬性的，不靠调用方自觉。"""
    def fire(self, t): if self.phase != 'IDLE': return False; ...
    def tick(self, t): # RELEASED 满 0.7s 时恰好一次返回 'stow'（回仓指令逐拍重试不放弃）

def aim_point(frozen, offset_body_xy, mission_yaw, vx, vy, params):
    """瞄准点 = 冻结时刻的活动估计 + 标定投放口偏置（机体系→世界，用锁定航向）
    + 弹道前移（带 sanity 钳位：|lead|>0.15m 时按比例截断）。"""
    c, s = cos(mission_yaw), sin(mission_yaw)
    ox = c*offset_x - s*offset_y;  oy = s*offset_x + c*offset_y
    lx, ly = ballistic_lead(vx, vy, params.release_height_m)
    ...  # 钳位
    return frozen.working_x + ox + lx, frozen.working_y + oy + ly, lx, ly
```

投放口偏置 `payload_offset_1/2` 来自标定两步法（§8），当前为占位 [0,0]。

## 8. 投放标定两步法（机械 → 算法的桥梁）

> 工具：`查阅区/08_参考/hgd_cudac/视觉标定/`。机械前提（轴线同轴 <5mm）见 02 结构模块 §8。

1. **静态标定（铅垂线法）**：飞机低位固定 → 投放口中心垂铅垂线 → 移动整机让线压目标中心 → 保持 ≥3s → 窗口内目标 FRD X/Y **中位数** = 该投放口静态偏置（Z 由机械测量）。每口独立（HIT 两口偏置差 5cm 量级）；工具 `estimate_static_offsets.py`；
2. **动态修正（真实试投）**：每载荷每高度 ≥3 次试投，`最终偏置 = 静态偏置 + 落点偏差中位数`，**MAD 作重复性指标**（MAD 大 = 问题在机械/延迟不在算法），覆盖舵机延迟、瓶体摆动、残余速度、气流；工具 `record_drop_trials.py` + `solve_drop_trials.py`；
3. **两准星分离原则**：目标准星与"载荷真实投放中心投影"准星分开画，载荷准星只用固有标定值——防止准星跟着目标跑、对准误差被隐藏；
4. **验收**：目标高度落点 **CEP<5cm**（≥20 次统计）；对准平面减桶高 0.30m。

## 15. 附：仿真推力标定方法（zd550 动力整定的推导，09-12）

取 gz-sim LiftDrag 源码精推：`T = 2·cl·½ρ·(cp·ω)²·area`——叶片入流恒沿 forward ⇒ α≡a0=0.3，`cl = cla·a0 = 1.275`，双叶纯竖直出力；CW 转子 forward 镜像、对称成立。方法：先**用原 iris 已知悬停 cmd≈0.53 交叉验证公式无误**，再从"单桨 29.5N"反解参数——全程无拍脑袋。产出 multiplier ±656（6264 rpm）、cmd_max ±4.0（满转速阻力矩 2.65 N·m；原 ±2.5 会饱和）。验证：悬停 PWM 1764（cmd 0.830）vs 模型预测 0.816，差 1.7%。

## 18. 自查题

1. 为什么时间插值在状态机侧做，而不是感知端补偿？（感知端只有机体系观测，没有 odom 历史；插值需要"取帧瞬间"的位姿）
2. `try_lock` 为什么要求排名签名稳定 0.8s？（排名抖动说明分类未收敛，锁了就会投错筒）
3. 重捕获为什么只有一次？（HIT 教训：多次重捕获 = 变相按旧坐标盲投）
4. `ReleaseGate.feed` 任一门控违约为什么清零两个计时器？"稳定 0.8s"必须是连续的
5. `aim_point` 里弹道前移为什么要钳位？（它是 sanity 不是补偿——正常悬停时 ≈0，超限说明速度门限已失守）
6. 参数改了代码不用改吗？（走 mission_params.yaml 注入；改默认值 = 改 SSOT 基线，要过评审）

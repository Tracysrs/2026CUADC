# 02 · 结构与硬件模块（机架 → 动力 → 装机接线 → 供电 → 投放机构）

## 怎样使用本文

- **装机时**：§3 接线总表是唯一接线依据，§4 供电架构 + §5~§7 分系统安装照做；
- **采购时**：§1.2 动力校核 + §9 采购清单；
- **材料边界**：设备详细调查报告在 `11_设备参数/ZD550.md` 与 `RTK-01.md`（含来源链接与存疑项），本文收录装机要用到的全部规格；接好后的"怎么调"在 [03_操作模块](03_操作模块.md)。

> ⚠️ **家规（连续三案血训：PPM 针序镜像、数传单向通、RTK 5V 反接，全是线缆）：
> 任何新线缆，上电前必过万用表，两头逐针。**

## 4. 供电架构（三级动力切断）

对应规则：技术要求 2.3"人工切断动力的安全开关" + 细则 5.7 进场演示 + 5.8 飞行中唯一人工操纵=紧急停止。

```
电池(6S/XT60)
  → ① 反火花总开关 Flipsky AS200（机械人工切断，5.7 裁判演示用；≥8S/≥60A/反火花预充/按键+LED）
  → XT60 一分三分线板（主路 12AWG，支路 18~20AWG，每根 ≤15cm）
      ├→ 4× 电调（动力）
      ├→ ② RC6 急停（SWC 拨杆 → RC6_OPTION=31，飞行中紧急停桨，不断电、日志完整）
      │     + ③ 自动失效保护（低电 21.6V RTL / 严重 21.0V Land）
      ├→ PMU 2 Lite → 飞控（5V）
      ├→ 6S→12V/5A 降压模块 → Jetson（DC 5.5×2.5 母头中心正）
      └→ 6S→12V 小降压（≥1A）→ 云台（与 Jetson 那块分开独立）
```

三级切断的分工逻辑：①是**机械**的（绝对可靠，裁判演示用，断电=日志中断靠总开关前的飞控日志复盘）；②是**固件**的（不断电、日志完整，飞行中唯一合规人工操纵）；③是**自动**的（无人介入兜底）。三者覆盖"演示/飞行中紧急/无人值守"三种场景。

**四条供电铁律（全部实锤过的坑）**：

1. **飞控不为舵机供电**——《Pixhawk V6X 使用手册》原文；A1~A8 的 +/− 是悬空母线（M1~M14 正负相通）。好盈 OPTO 电调又无 BEC → 全系统没有任何 5V 源。**必须 UBEC 5V/3~5A 注入 A1 母线并与飞控共地**。应急替代：充电宝+剪 USB 线、4×AA 电池盒（6V 在舵机规格内）；从 Jetson USB 取电有拖垮风险，不推荐久用。
2. **6S 满电 25.2V 不可直连 Jetson**——Orin DC 口上限 19V；降压模块接前万用表调准电压。
3. **云台输入上限 16.8V**（4S 满电级），必须独立小降压，**不与 Jetson 的共用**——保住"舵机动作不重启 Orin"的 20 次压力测试结论。
4. **Orin 独立供电压测**：舵机满负载动作 20 次不重启才算数（SSOT P1-2）。

**上电纪律（云台说明书红字）**：先装相机再上电（空载会不停抖动）；通电后挂起离地、静置稳定约 20s 听到一声响才算就绪，期间不要晃动。若上 GoPro：**WiFi 必须关**（2.4G 与 FS-i6 同频段）。控制从简：比赛用**锁定模式固定角度**最省（FS-i6 六通道已满）；真要动态控俯仰，走飞控 A3/SERVO11 出 PWM，别挤遥控通道。

### 5.2 电机编号、方向与装桨表（✅ 09-09 验收通过）

电机：YH 4120（定子 41×20mm，KV340，外转子；MDPI《Drones》论文佐证 YH4120+XRotor 40A 组合；满油门约 25~35A/台）。
ArduPilot Quad X（FRAME_CLASS=1 / FRAME_TYPE=1）标准布局，源码 `AP_MotorsMatrix.cpp` 三重交叉验证：

| 输出口 | 位置（俯视，机头朝前） | 应转方向（俯视） | 装哪种桨 |
|---|---|---|---|
| M1 | 前右 | 逆时针 CCW | 常规桨 |
| M2 | 后左 | 逆时针 CCW | 常规桨 |
| M3 | 前左 | 顺时针 CW | 反桨（R） |
| M4 | 后右 | 顺时针 CW | 反桨（R） |

规律：**对角同向、相邻反向**。

历史教训：第一轮实测四台**全部反向**（出厂电调方向 = Betaflight 默认：FR/RL 顺、FL/RR 逆），不是接线错位——每台对调**三根相线中任意两根**即修正。日后更换电调/电机，先 `motor_test.py` 复测再装桨（命令见 03 操作模块 §2.4）。

⚠️ 桨保（SSOT P1-1 强制）：比赛与试飞必装；电机螺丝/桨保/限位紧固是上场检查表项（HIT 9.5 电机飞出炸机教训）。

## 6. 接收机接线（FS-iA6B ↔ V6X，针序镜像坑）

| V6X PPM IN 座（GH1.25，3 针） | 信号 | FS-iA6B CH1 针（舵机序 S/+/−） |
|---|---|---|
| 5V+ | → | 中间针 **+（VCC）** |
| PPM IN | → | 一端 **S（信号）** |
| GND | → | 另一端 **−（GND）** |

⚠️ **针序镜像，直通杜邦线 = 电源反接**：飞控中间针是**信号**、两端是 GND 和 5V+；接收机中间针是 **VCC**、两端是 S 和 GND。直排对接 = RX 的 GND 撞上飞控 5V+、RX VCC 撞上信号针——这就是"信号线一碰接收机就掉电"的根因（前两次排障怀疑"错位怼到 5V/GND"，其实**不错位的直通线才是错的**）。接线前上电用万用表实测：找出唯一 ~5V 针、通地针，剩下是信号。

其他要点：

- V6X 的 PPM 是**独立专用座**；DSM/SBUS 是另一个 5 针座（含 SPEKTRUM_3V3 3.3V 针），**别用那个座给 iA6B 供电**；
- iA6B 供电 4.0~8.4V，取 PPM IN 座 5V+/GND 即可；对频已成功（LED 常亮）；
- 历史教训：iA6B **没有 SBUS 输出**（只有 PWM/iBUS/PPM）——按 SBUS 接全零是场误会；PPM 波形由接收机硬件合成，FS-i6 菜单无 PPM 开关项，LED 常亮即应有输出；
- 遥控器端三件（SWA→CH5 模式、SWC→CH6 急停、failsafe 改 No pulses）见 03 操作模块 §2.7。

## 7. 外设安装

### 7.1 GPS（NEO-3）

- 装机 GPS1 口，**上桅杆**远离干扰源；安全开关/蜂鸣器随 GPS1（不可省）；
- 罗盘：**RM3100（NEO-3 外置）勾 External 当主罗盘；IST8310（V6X 板载）取消 External** 仅备份——勾反 = 板内受扰罗盘当主用 = 航向漂/EKF 拒定/炸机；改完 Reboot **必须重跑罗盘校准**；
- 室内 0 星属正常，勿误判坏件；室外验收标准（3D Fix + ≥8 星 + HDOP<1.5）见 03 操作模块。

### 7.2 RTK（瑞杰 RTK-01-R 机载端，备用/测试）

- 接 **GPS2** 口（GH1.25-6P），**不占 GPS1**；模块箭头朝机头，远离电调/电源线（自带 QMC5883 罗盘），别与 NEO-3 上下叠硬挤；
- ⚠️ **rover 6P 针序（1=GND/2=SCL/3=VCC/4=RX/5=SDA/6=TX）与 Pixhawk GPS 标准（1=VCC/2=TX/3=RX/4=SCL/5=SDA/6=GND）完全相反**——1对1直通 = 5V 进 GND 脚（09-11 实锤反接，灯不亮）。首选原配 `A1254WF-06A` 线，自制转换映射：**1→3、2→4、3→6、4→2、5→5、6→1**，上电前万用表逐针；
- Type C 仅供电/厂商 APP 通道，NMEA 走 6P UART（8 波特率扫描全零后的结论）；
- 基站 RTK-01-B：天线架高 1.5~2m、天顶开阔、远离反射面（**多径是 Fix 收敛慢第一杀手**）；Type C 供电（充电宝可带，260mA）；上架后**全程禁动**；
- 参数与验收分级见 03 操作模块 §4；定位策略（默认不上场）见同 §4。

### 7.3 数传（远航 3DR Radio X6）

- 机载版（TTL 带 GH 插头）→ TELEM1；地面版（USB）留地面笔记本——分不清哪只装机：带 GH 插头/裸 TTL 的装机；
- **天线先拧紧再上电**——无天线发射可能烧功放（数传唯一容易真损坏的操作）；
- 机上走线：天线朝下或朝侧**露出机架边缘**，别贴碳板、别与电源线捆扎（碳架屏蔽 + 干扰）；
- 连接与频点操作见 03 操作模块 §3。

### 7.4 TFmini 激光

TELEM3 接线（TX/RX 交叉 + 共地），SERIAL5=11/115 参数已配好（懒加载恢复见 03 操作模块 §2.2 临时参数台账）；安装朝下视方向（RNGFND1_ORIENT=25），`RNGFND1_GNDCLR` 按实际安装离地高度改（当前 0.1m 占位）；驱动 20=串口版 TFmini（25 是 I2C 版，勿混）。

### 7.5 Jetson 与相机

- Jetson 台架形态：飞控 USB-C ↔ Jetson USB（udev 别名 `/dev/cuadc-fc`）；目标形态：TELEM2 ↔ 40-pin UART @921600（接线后切换验证待做）；
- 相机下视安装（规格与曝光见 01 视觉模块 §1）。

## 8. 投放机构（结构侧）

- **两路独立舵机 + 释放爪**（A1=SERVO9 / A2=SERVO10），互不共用机械件（一路卡死另一路仍可投）；
- ⚠️ **图纸评审硬指标：舵机推力轴线与水瓶质心同轴 <5mm**——这是冠军队 15cm 小桶投不中的机械根因，**必须在投放标定前解决**（标定算法见 04 算法模块 §8）；
- 两瓶挂载：带两瓶水飞越起飞线才有起飞分；瓶在位检查进上场检查表；
- 供电：UBEC 5V 注 A1 母线（§4 铁律 1）；PWM 时序（收拢 1100/释放 1900/保持 0.7s）与验收命令见 03 操作模块 §6。

## 10. 电气机械坑速查（详见 [06_坑清单与排障](06_坑清单与排障.md) §6/§10）

| 坑 | 根因/解法 |
|---|---|
| 飞控电压读 0.00V（电池已接、电调在叫） | PMU 6pin 小线没插飞控；主电听电调、PMU 看读数，两维度独立 |
| 舵机完全不动 | 系统无 5V 源（OPTO 无 BEC + 飞控不供舵机）→ UBEC 注 A1 母线并共地 |
| 接收机"信号线一碰就掉电" | PPM 针序镜像，直通线 = 电源反接（§6） |
| 电机四台全反 | 出厂 = Betaflight 方向，相线对调任意两根修正 |
| 电调红线插飞控 | OPTO 无 BEC，红线悬空包好 |
| iA6B 出厂 failsafe="保持" | FS-i6 端改 No pulses，否则关遥控飞控察觉不到断链 |
| 6S 满电直连 Jetson/云台 | 超压烧件；各自独立降压，接前万用表调准 |
| RTK rover 灯不亮 | 6P 针序与 Pixhawk 标准相反，直通 = 5V 反接（§7.2） |
| 数传单向通 | TX/RX 没交叉；地面注入测试定位，对调信号线秒通 |

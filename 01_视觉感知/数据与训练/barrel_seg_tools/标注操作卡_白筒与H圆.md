# 标注操作卡 · 白筒 seg 与 H 圆 det（v4 提取数据 + 实拍数据通用）

> 适用范围：`dataset_v4` 提取出的**投弹筒（类 10/11/12）**与 **landing_H（类 13）**图片，
> 以及后续按《采集操作卡_白筒与H圆.md》新拍的实拍图——两路数据**同一套标注标准**。
> 关联：采集操作卡（同目录）｜SSOT §8.2 训练验收 / §8.4 采集计划｜`build_barrel_dataset.py` /
> `run_barrel_training.sh` / `run_hmarker_training.sh`（同目录）。
> **⚠️ v4 的标签是检测框，白筒 seg 流水线不收检测框**（`build_barrel_dataset.py` 头部警告），
> 投弹筒图必须重标多边形；H 圆用检测框即可。

---

## 一、总览：两类图、两种标签、两个去处

| 提取来源（v4 类 id） | 去向数据集 | 训练脚本 | 标签格式 | 类别定义 |
|---|---|---|---|---|
| 投弹筒 1/2/3 号（10/11/12） | `barrel_seg_v1/`（seg） | `run_barrel_training.sh` | YOLO-seg 多边形：`0 x1 y1 x2 y2 …`（归一化，≥6 点） | **单类 0=barrel**；三规格不分类、1/2/3 号不分 |
| landing_H（13） | `hmarker_v1/`（det） | `run_hmarker_training.sh` | YOLO det：`0 cx cy w h`（归一化） | **单类 0=h_marker** |

为什么投弹筒合并成单类：bucket 感知端（`bucket_perception_node`）只要筒口椭圆做投放对位，
直径由几何反算、编号与 seg 无关；将来若任务需要"识别筒号"，另走一条 det 线单独标，不混进 seg 集。

## 二、工具准备

1. **X-AnyLabeling**（推荐，内置 SAM 辅助）或 labelme（需手转格式）；
2. SAM 模型在 X-AnyLabeling 里选 `sam_hq_vit_b` 级别即可（够用且快）；
3. **det 框转初值**：v4 提取出的 YOLO det txt 先脚本转 labelme json 导入
   （转换脚本随提取包交付，把 `10/11/12/13` 类框画成矩形），框只当 SAM 的提示，不当最终标签；
4. 快捷键先记三个：`D` 下一张、SAM 点选生成多边形、`Ctrl+Z` 撤销——白筒标注 90% 时间在这三个键上。

## 三、白筒 seg 标注规范（多边形）

### 3.1 画什么
- 沿**筒口外沿**画闭合多边形（俯拍看到的是椭圆口）——**不是筒底、不是阴影、不是筒身反光亮斑**；
- 椭圆口 8~16 个点足够（`dataset_audit.py` 有 seg 点数检查，点太少报错）；圆正俯拍时可 8 点均匀放；
- 斜视角下筒口呈扁椭圆：沿可见口沿布点，长短轴各 4~8 点。

### 3.2 困难样本处理（采集卡特意要的，标注别偷懒退掉）
| 情形 | 画法 |
|---|---|
| 半遮挡（邻筒压边） | 沿**可见部分**口沿画，遮挡边贴遮挡物轮廓 |
| 被画面边缘截断 | 沿可见口沿画，出画边贴图像边（坐标可取 0/1） |
| 侧倒（横躺筒） | 沿可见**筒身轮廓**画（此时口沿在侧面，标整段可见筒身） |
| 阴影压住筒口 | 口沿看得到就照标；阴影里的假边缘不要跟 |

### 3.3 直接丢弃（宁缺毋滥）
- 糊到认不出筒口轮廓的帧；
- 筒口占比 <15×15 px 的远景帧（audit 会报零/微面积）；
- 同一片段里和已标帧几乎一样的冗余帧（挑帧纪律见第五节）。

### 3.4 标签文件示例
`labels/0001_frame_0042.txt`（三筒同框时三行）：
```
0 0.512 0.498 0.538 0.472 0.556 0.501 0.531 0.527 0.508 0.522
0 0.215 0.610 0.241 0.584 0.259 0.613 0.234 0.639 0.211 0.634
0 0.780 0.355 0.806 0.329 0.824 0.358 0.799 0.384 0.776 0.379
```
（首列为类别 0；其后为多边形顶点 x1 y1 x2 y2 …，均归一化到 0~1）

## 四、H 圆 det 标注规范（检测框）

- 框**贴白圆外沿**的正外接矩形，不带地面背景——这条链的"直径-高度一致性"质量门控
  （`h_circle_node`）对框的直径敏感，**框不准不如不标**（Hough 兜底反而更稳）；
- 斜视角：按可见椭圆的**外接矩形**画；
- 半出画：按可见部分外接矩形，坐标允许贴 0/1 边界；
- 黑 H 图案方向（正/斜 H）不做区分——单类；
- 无 H 的帧保留当背景负样本（空 txt）。

## 五、文件命名与切分纪律（防泄题，脚本强制执行）

1. 文件名沿用片段惯例：`<片段号>_frame_<NNNN>.jpg`（如 `0003_frame_0042.jpg`）；
   v4 提取帧按其原始视频来源重建片段号，提取脚本会带；
2. **同一片段绝不跨 train/val**——`build_barrel_dataset.py` 按片段号切分，标注阶段不用管，
   但**挑帧阶段要管**：同一视频连续帧高度相似，**隔 5~10 帧标一张**，省人时且天然防泄漏；
3. 纯背景帧（无目标）保留，交付目录里配同名空 txt 当负样本；
4. 图片统一 jpg；标注 txt 与图同名。

## 六、标注完成后：自检 → 建集 → 训练 → 验收

```bash
# 1. 审计（类别数=1；查越界/零面积/seg 点数/图签互缺/精确重复图）
python dataset_audit.py --images <标注目录>/images --labels <标注目录>/labels --classes 1

# 2. 白筒建集（合成集+实拍集合并、按片段切分、出 barrel_seg_v1/ 交付目录）
python build_barrel_dataset.py --synth <合成集> --real <实拍标注集> --out barrel_seg_v1

# 3. 训练（白筒 seg；H 圆 det 可传 helipad 预训练初值）
bash run_barrel_training.sh barrel_seg_v1
bash run_hmarker_training.sh hmarker_v1 [helipad.pt]
```

验收线：白筒=SSOT M2（实拍白筒检出 ≥95%、机载 ≥25FPS）；H 圆=M4 联调。
版本台账：`dataset_version.md` **双镜像**（deliver_v2/ 与 hazard_hgd_10cls_v2/）照例同步。

## 八、常见错误（每条背后都有真实教训）

1. **det 框直接混进 seg 集**——流水线不兼容，build 脚本直接报错（v1 合成集前车之鉴）；
2. **按名字猜类别**——哈工大集"标签名与图案不符"翻过车；本卡两线均单类，无此风险，
   但**扩类时必须按图案标**；
3. **多边形跟筒底阴影走**——口沿才是投放对位的真目标；
4. **连续帧随机切分**——val 与 train 同视频=泄题（09-05 教训，脚本已防，但挑帧靠人）；
5. **H 圆框带一大圈地面**——质量门控把假直径当真，投放对位偏移；
6. **糊帧硬标**——训练吃进噪声，验收掉坑；丢弃是合法操作。

# 采集操作卡 · 白筒实拍 + H 圆自制（视觉线最后的数据缺口）

> 对应 SSOT §8.4 采集计划；拍摄基线照《06_使用说明书/05_视觉模块》§1.2
>（**快门 ≤1/500s、手动锁曝光**——当前 BL-500W-335 固件红线待解，采集前先确认曝光方案）。
> 采集完成后走 `build_barrel_dataset.py` 建集 → `run_barrel_training.sh` 训练。

## 一、白筒实拍（目标 ≥600 张，三规格全覆盖）

### 器材
- 白筒三规格：ø15cm、ø20cm、ø25cm（高 30cm，PVC/纸筒喷白漆即可）；
- 地面：**蓝底**（有效区色）与**水泥地/浅灰**各一批（无效区"以现场为准"，灰地必须覆盖）；
- 相机：真机 BL-500W-335（训练分布=真机成像，别用手机凑数——01 视觉模块 §6.1 教训）。

### 拍摄矩阵（每格 ≥30 张，轻微移动/换角度）

| 维度 | 取值 |
|---|---|
| 高度 | 2.0m（搜索主高度）为主，1.5 / 3.0 / 4.0m 各一批 |
| 角度 | 正下视为主 + **斜视角**（画面边缘 30~45° 入射）|
| 布景 | 单筒 / 两筒（近距 0.3~0.5m 摆，考验独立性）/ 三筒全景 |
| 遮挡 | 无遮挡为主 + 少量半遮挡（相邻筒压边）|
| 光照 | 开灯室内 / 阴天户外 / 晴天硬阴影（**阴影压住筒口**的特写必须有）|
| 背景 | 蓝地 / 灰地；包含干扰物：地面标线、亮反光块、白桶**打翻侧倒** |

### 标注
- 工具：任意 YOLO-seg 多边形标注器（X-AnyLabeling / Roboflow / labelme 转换）；
- 类别只有 **0 = barrel**（三规格不分类，直径感知端反算对号）；
- 多边形贴**筒口外沿**（不是筒底阴影）；
- 无标注帧（纯背景）保留 → 建集脚本自动补空标签当负样本；
- 文件名带片段号：`0001_frame_0001.jpg`（**连续帧同片段**，切分脚本按片段防泄漏）。

## 二、H 圆自制（目标 ~200 张）

### 制作
- 底布 ø80cm 白色圆（防水材料，比赛贴地要平整）；
- 中间黑 H：两竖杠 + 横杠（竖杠高 ~50cm、宽 ~10cm、间距 ~45cm，按常规 helipad 比例）；
- **黑 H 白底制式写进采集卡即为本队标志定案**——h_pattern_score 打分假设此前提，做红底/蓝底版本需同步改视觉参数并重验。

### 拍摄矩阵

| 维度 | 取值 |
|---|---|
| 高度 | 4.0 / 2.0 / 1.5 / 0.8m（降落段从进场到贴地全覆盖）|
| 角度 | 正下视为主 + 斜视角（H 圆在画面边缘 1/3 处）|
| 布景 | 起降区地砖/草地/水泥地；圆心偏画面九宫各位置 |
| 干扰 | 地面白线圈、其他白色圆形物（脸盆/胶带卷）同框 |
| 光照 | 与白筒同三档；傍晚低角度光一批 |

### 标注
- 类别 **0 = h_marker**，检测框贴白圆外沿；
- 同样按片段命名；无 H 帧保留当背景。

## 三、（顺路）危化 v3 补数

白筒/H 圝拍摄同场顺带：**刺激性(id2)/放射性(id3)** 实拍 ≥60 张/类（蓝地场景）+
蓝地无标识背景 ≥50 张（v2 混淆矩阵背景误报集中于此）——类别表照 01 视觉模块 §2.1。

## 四、验收自检（建集前过一遍）

- [ ] 三种筒径每类 ≥150 张有效标注实例？
- [ ] 斜视角样本占比 ≥20%？（正下视 95% 上场地 5% 翻车的教训）
- [ ] 硬阴影 / 侧倒筒 / 干扰白块三类困难样本各有？
- [ ] H 圆 0.8m 高度近景（画面占满）样本 ≥30 张？（降落末段最难）
- [ ] 文件名片段号规范，无"拍摄当日未导出、混在手机相册里"的？

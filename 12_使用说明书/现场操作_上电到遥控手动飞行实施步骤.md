# 现场操作清单：从装电源到遥控手动飞行（含解锁排障）

> 适用：CUAV V6X-V2 + ArduPilot 4.7-beta + ZD550 四轴（6S 8000mAh / PMU 2 Lite-5V / NEO-3 GPS / SBUS 遥控）。
> 遥控约定：Mode 2（左杆=油门/偏航，右杆=俯仰/横滚）。
> 铁律（SSOT §7）：真机首测**拆桨**；解锁测试全部通过才装桨。
>
> **使用方法**：按阶段 A→E 顺序执行，逐条勾选；每条都是「动作 → 合格标准 →（工具）」。
> 卡住不动 → 查附录 A 报错速查；空中异常 → 背附录 B 应急处置；命令/数值 → 查附录 C。
> 建议打印纸质版，飞行中不碰电脑。

## 阶段 0：解锁排障 —— 先搞清"为什么锁不上"（约 5 分钟）

> 原则：**先读报错，不盲改参数。** V6X + ArduPilot 解锁被拒必有一条 `PreArm: xxx`。

- [ ] 0.1 电脑连飞控（USB 或数传），打开地面站消息页
  合格标准：能看到滚动消息 →（Mission Planner → 飞行数据 → 消息；或 `python check_fc.py`）
- [ ] 0.2 触发一次解锁尝试：油门压最低 + 偏航推最右，保持 3 秒
  合格标准：消息页出现一条 **`PreArm: xxx`** → 记下关键字
- [ ] 0.3 拿关键字查 **附录 A**，按"处理"列修复
  合格标准：修复后重推解锁杆，报错消失或变为下一条 → 逐条消灭直到解锁成功
- [ ] 0.4 参数核对（若之前跑过 `fc_armrun.sh` / `fc_armtest.sh` 干跑）
  合格标准：无意外差异 →（`python verify_params.py --diff ../../01_设计/V6X_ardupilot_params.param`）

> 最常见的隐藏项：**硬件安全开关在安全态** —— V6X 安全开关**连按两下**（红灯快闪→灭）再试解锁。

## 阶段 1：装电源上电（约 5 分钟）

- [ ] 1.1 电池体检：外观无鼓包破损，量总压
  合格标准：**满电 25.2V**；低于 22.2V 换电；单节压差 <0.05V
- [ ] 1.2 电源链路确认：电池 XT60 → PMU 2 Lite-5V → 6P 线 → 飞控 POWER 口，插紧
  合格标准：接口到位无松动
- [ ] 1.3 清理调试线：Jetson 串口等非必要线断开；电脑 USB 可留（仅供电）
  合格标准：不影响起飞重量与走线
- [ ] 1.4 装电池：扎带固定，重心对准机架中心
  合格标准：晃动机体不滑移
- [ ] 1.5 **先开遥控器 → 再接电池**
  合格标准：遥控器先开机，防止上电瞬间失控
- [ ] 1.6 上电后机体放平**不要碰**，等待约 10 秒
  合格标准：自检蜂鸣正常、LED 正常、安全开关红灯闪烁（= 安全态，正常现象）
- [ ] 1.7 地面站核对电压
  合格标准：显示电压与实测差 <0.3V（差大了电流计需校准）

## 阶段 2：上电检查 + 地面解锁测试（拆桨状态，约 10 分钟）

### 2A 起飞门禁七项

- [ ] 2.1 GPS：3D Fix、**≥8 星、HDOP<1.5**、家点已设置 →（`check_gps.py` 或 MP 状态页）
- [ ] 2.2 EKF/罗盘：EKF 绿、罗盘一致性正常 →（MP 快速页）
- [ ] 2.3 飞行模式：当前为 **Stabilize 或 AltHold**（首飞禁用 Guided/Loiter）
- [ ] 2.4 遥控通道：拨动右/左摇杆，MP 的 RC 页通道 1~4 跟随、油门中位 ~1500
- [ ] 2.5 RC 失控保护：**关掉遥控器**，MP 应报 RC failsafe；开回恢复
- [ ] 2.6 安全开关解除：连按两下安全开关
  合格标准：红灯由快闪变灭
- [ ] 2.7 参数：`verify_params.py --diff` 已核对无意外差异

### 2B 地面解锁测试（必须仍拆桨）

- [ ] 2.8 解锁：油门最低 + 偏航最右 3 秒
  合格标准：电机进入怠速
- [ ] 2.9 轻推油门 ~20%
  合格标准：四电机同时响应、无异常抖动/异响
- [ ] 2.10 上锁：偏航最左 3 秒
  合格标准：电机停转
- [ ] 2.11 重复 2.8~2.10 一遍
  合格标准：两次全部干净利落 → 阶段 2 通过

## 阶段 3：装桨（约 5 分钟）

- [ ] 3.1 **先拔电池**再动手
- [ ] 3.2 按 `motor_test.py` 已验证的旋向装桨：正反桨与电机转向一一对应
  提示：X 型四旋翼对角同向；同轴两桨绝不能互换
- [ ] 3.3 桨帽拧紧、桨叶无裂纹缺口
- [ ] 3.4 装桨后纪律：**手、脸、衣物永远离开桨盘平面；通电即视为"活体"**

## 阶段 4：遥控首飞（三段验证，每段落地一次）

### 4A 准备

- [ ] 4.1 环境：空旷场地，半径 15m 内无人，上风头起飞，GPS 家点=当前点
- [ ] 4.2 模式开关映射：一个开关映射 Stabilize / AltHold / Loiter 三档
  合格标准：MP 模式页拨开关逐档回读确认 →（`FLTMODE1~3`）

### 4B 第一段：Stabilize（手动）

- [ ] 4.3 解锁：油门最低+偏航最右 3 秒，听到提示音
  提示：解锁后 60 秒内不离地可能被固件超时上锁，动作要连贯
- [ ] 4.4 起飞：油门**缓慢**推过中点，离地 1~2m 悬停
  提示：8~10kg 机体怠速到离地行程很短，防"窜升"
- [ ] 4.5 悬停观察 20 秒：右手轻修正姿态，轻微漂移属正常
  合格标准：全程可控
- [ ] 4.6 降落：油门缓收到落地，落稳后压最低 3 秒上锁

### 4C 第二段：AltHold（高度自稳）

- [ ] 4.7 重新解锁起飞至 3m，切 AltHold，**油门回中**
  合格标准：高度自稳不动
- [ ] 4.8 上/下拨油门各一次
  合格标准：响应平顺 → 降落

### 4D 第三段：Loiter（定点）+ RTH 演练

- [ ] 4.9 解锁起飞至 5m，切 Loiter
  合格标准：定点悬停 ±0.5m 内
- [ ] 4.10 轻拨右摇杆走位再回中
  合格标准：自动刹车回位
- [ ] 4.11 触发一次 RTH（地面站或专用开关）
  合格标准：升高到 `RTL_ALT`、飞回家点上方、缓慢自动降落；不满意**随时切 Stabilize/Loiter 人工接管（人工接管永远优先）**
- [ ] 4.12 正常降落：缓收油门，触地后油门最低保持 3 秒自动上锁
- [ ] 4.13 落地后：拔电池 → 检查桨叶/电机温度与紧固 → 查看电池电压（记录用掉多少）

> 手动三段全部通过后，才进入 GUIDED 任务状态机流程（`fc_dryrun.sh` → `fc_armrun.sh`）。

## 附录 A：PreArm 报错速查

| PreArm 报错 | 根因 | 处理 |
|---|---|---|
| `RC not calibrated` / `Radio ...` | 遥控没对上频 / 通道没校准 | MP → 遥控器校准全程走一遍；确认接收机 SBUS 线插 RC/SBUS 口、遥控器协议一致 |
| `Compass ... inconsistent` | 罗盘未校准 / 内外磁偏角差大 / 磁干扰 | MP 罗盘校准；优先用 NEO-3 外置罗盘；远离钢筋/磁铁挪位重试 |
| `AHRS: waiting for home` / `Need Position Estimate` | GPS 没定位（室内必报） | 移步室外；跑 `check_gps.py` 验收 3D Fix+≥8星+HDOP<1.5；室内台架测试才临时减 `ARMING_CHECK`（**测完必须恢复**） |
| `Gyro cal failed` / `AHRS gyro` | 上电时被晃动 / 温度未收敛 | 上电后放平 10 秒不碰；重启飞控重标定 |
| `Accels not calibrated` / `Baro not healthy` | 加速度计没校准 / 气压孔堵塞 | MP 六面校准；检查气压计开孔 |
| `Battery failsafe` / 电压过低 | 低于 `BATT_ARM_VOLT` | 换满电电池；6S 满电 25.2V，<22.2V 禁飞 |
| `Motors ...` / `ESC ...` | 电调未上电 / 输出映射错 | 拆桨跑 `motor_test.py` 核对 M1→M4 顺序与 SERVO1~4_FUNCTION |
| 无报错但推杆没反应 | 硬件安全开关在安全态 | 安全开关**连按两下**；或 `BRD_SAFETYENABLE=0` |

> 补充：`fc_armrun.sh`/`fc_armtest.sh` 曾临时放宽 `ARMING_SKIPCHK`/`FS_THR_ENABLE`，
> 干跑中断后参数可能未恢复 → 用 `verify_params.py --diff` 全量核对。

## 附录 B：应急处置（空中，先背这张表）

| 情况 | 动作 |
|---|---|
| 姿态失控 | **立即切 Stabilize**，右手回中，靠油门控高度迫降 |
| RC 失控（遥控器断联） | 别慌：`FS_THR_ENABLE` 默认自动 RTH，等数秒；信号恢复即人工接管 |
| 电池低压报警 | 立即就近降落，不飞回原点 |
| 炸机/翻覆 | **先拔电池再靠近**；查桨/电机/飞控减震 |
| 异常抖动 | 降落后拉 dataflash 日志（`fc_log_pull.py`），重点看振动值与 EKF |

## 附录 C：命令与关键数值速查

**推荐用法：统一入口 `ops.py`**（在 `03_工具/飞控调试/` 下，按本清单阶段分类，`python ops.py` 打印菜单，参数原样透传）：

| 阶段 | 命令 |
|---|---|
| 阶段 0 排障 | `python ops.py fc`（读报错）、`python ops.py prearm`（解锁前诊断：模式/RC/电池/EKF/罗盘一致性一次看全，只读）、`python ops.py params-diff ../../01_设计/V6X_ardupilot_params.param` |
| 阶段 2 检查 | `python ops.py gps`（GPS 验收）、`python ops.py radio`（数传，默认 COM10）、`python ops.py geo`（场地就地测试，`geo here` / `geo record 60`） |
| 阶段 3 动力 | `python ops.py motor COM5`（**拆桨**；可带输出号如 `motor COM5 3` 只转 M3） |
| Jetson | `python ops.py dryrun / armrun / armtest / servo-test / servo-diag / log` |

**原始脚本**（`ops.py` 即封装自这些，也可直接调用；Windows 下 `python`，Jetson 上 `python3`）：

| 命令 | 用途 |
|---|---|
| `python check_fc.py` | 连飞控读版本/模式/电池/GPS/姿态 |
| `python check_gps.py` | GPS 验收（室外：3D Fix + ≥8星 + HDOP<1.5） |
| `python verify_params.py --diff ../../01_设计/V6X_ardupilot_params.param` | 参数一致性核对 |
| `python motor_test.py COM5`（拆桨） | 电机顺序/方向，严格 M1→M4 逐个 1 秒 |
| `python site_geo_check.py` | 场地 GPS/罗盘/EKF 就地测试（比赛场地理数据核对） |
| `python fc_log_pull.py list` / `get x.BIN` | 拉 dataflash 日志（Jetson 上） |

**关键数值**：

| 项 | 数值 |
|---|---|
| 6S 满电 / 禁飞线 | 25.2V / 22.2V |
| GPS 验收 | 3D Fix，≥8 星，HDOP<1.5 |
| 油门中位（RC 通道 3） | ~1500 |
| 解锁 / 上锁 | 油门最低+偏航最右 3s / 偏航最左 3s |
| 安全开关解除 | 连按两下（红灯快闪→灭） |
| 首飞模式顺序 | Stabilize → AltHold → Loiter → RTH 演练 |
| 使用注意 | 地面站先断开 Mission Planner 再跑脚本；COM 号重启会变 |

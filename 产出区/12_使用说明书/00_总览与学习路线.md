本文与全套模块文档里的内容分三类，可信度不同：

| 类型 | 标记 | 含义 |
|---|---|---|
| 事实 | （无标记） | 实测验证过的结论，有日志/源码背书，可直接照做 |
| 约定 | "定案 / 基线 / 铁律" | 团队决策，改它要走 SSOT，不许顺手改 |
| 占位 | "占位值 / 待实测 / 待标定" | 尚未验证的假设（如场地几何、payload_offset），用前必须实测替换 |

## 1. 项目一句话与终点形态

**2026 中国大学生飞行器设计创新大赛（CUADC）· 多旋翼无人机侦察与救援项目**的全套自研系统：
一架 ZD550 四旋翼，在无人工干预下自主完成——**起飞 → 视觉搜索白筒 → 精准空投两瓶水 → 危化品标识侦察判读 → 返航精准着陆**，全程 ≤5 分钟。

```
起飞(4m) → 低空搜索白筒(2m) → 视觉锁定 3 个投放筒 → 对准空投 2 瓶水
        → 爬升侦察 3 块危化品标识 → AI 判读类别 → 数传回传填单
        → 返航 → 视觉精准降落 H 圆 → 自动上锁
```

- 得分构成：起飞 50 + 空投 **800** + 侦察 300 + 着陆 50 + 时间分 200 ≈ **1400 上限，冲奖 1250+**；
- 竞争标杆：哈工大冠军队（HIT，`查阅区/08_参考/hgd_cudac/` 全开源）区赛单轮最高 1328 分 / 最快 73s；**1300 与 900 的差距就是 15cm 小桶能不能投中**。

## 2. 系统架构

```
地面：Mission Planner 地面站 ←433MHz 数传(TELEM1)─┐
                                                    │
天上：Jetson Orin Nano（大脑，ROS 2 Humble）         │
  ├─ 下视相机 → YOLO 检测(TensorRT FP16) → 单目解算筒位│
  ├─ 危化标识分类(10类+拒识) → 数传回传填单           │
  ├─ 18 态任务状态机（自主决策）+ 安全监控（M4）       │
  └─ MAVROS ──MAVLink── TELEM2 @921600 ──► CUAV V6X 飞控（小脑）
                                            ├─ GPS NEO-3 定位 + RTK 备用
                                            ├─ TFmini 激光定高
                                            └─ 电调×4 → 电机×4 → 舵机×2 投放
```

数据流一句话：**感知数据只往上（飞控→Jetson），控制指令只往下（Jetson→飞控），地面站只看和填单**——程序绝不与飞手抢权，飞手切走 GUIDED 程序立即退让。

## 附录 B · 新手最容易犯的 20 个错误（每条都有真实前科）

1. 连飞控不关 Mission Planner → 脚本连不上 COM 口；
2. COM 口消失就以为变砖 → 其实重启漂移，扫口即得；
3. 参数只导一遍 → 懒加载参数组没激活，功能静默失效；
4. 写旧参数名（WPNAV_SPEED/BATT_LOW）→ 静默忽略不报错；
5. ATC_ANGLE_MAX 写 3500 → 这版单位是度；
6. 新固件不改 FRAME_CLASS/TYPE → 电机映射乱；
7. 直通杜邦线接 PPM/数传/RTK → 针序镜像/未交叉/反接三连坑；
8. 电调红线插飞控 → OPTO 无 BEC，红线悬空包好；
9. 舵机不动就怪飞控 → 先查有没有 5V 源（UBEC）；
10. 只插 USB 测电机 → 电调无主电，电机不转还误报低压；
11. 裸 MAVLink 做校准 → ACK 但静默不执行，必须 MP GUI；
12. 写参数后立刻重启 → 参数没刷进存储，丢了（等 5 秒）；
13. 用 `ros2 topic echo --once` 判断连接 → DDS 假阴性，看任务节点日志；
14. MAVROS 没数据就重启 → 先想 GCS 心跳泵和 set_message_interval；
15. Jetson 上 pip 装 anything 不盯 numpy → 升 2.x 炸 cv2；
16. engine 在比赛日现场导出 → 双绑定+9min46s，绝不现场构建；
17. 训练改默认增强参数 → hsv_h 大了制造标签噪声，lr 没降毁权重；
18. AutoDL 跑完不关机 → 烧钱；
19. 连续帧随机切训练集 → 验证泄题，分数虚高上场翻车；
20. 仿真调好的姿态参数直接上真机 → 1.5kg 和 8kg 不可互转。

## 附录 C · 新人必须会回答的十个问题

1. 上场只有 1 分钟，系统靠什么做到"上电即跑"？（预加载 + 黑帧预热 + suspend；systemd 自启不能 SSH 手拉）
2. 比赛为什么敢让 AI 侦察结果留空？（错填 −100，留空 0 分；拒识双阈值 τ=0.7/margin=0.3）
3. 为什么不用 RTK？（HIT Fix 收敛 3h37m + 干扰申诉不受理；我们有 12 手册五条件，默认不启用）

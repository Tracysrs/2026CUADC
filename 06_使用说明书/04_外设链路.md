# 04 · 外设链路（数传 / RTK / GPS / 激光定高）

> **本册索引**：§1 总则 → §2 数传（远航 3DR Radio X6） → §3 RTK（瑞杰 RTK-01） → §4 GPS（NEO-3） → §5 激光定高（TFmini） → §6 自查题。
> **分工**：每设备三段——安装（指针级位置，接线卡在 [02_装机接线](02_装机接线.md) §9）→ 参数配置（权威表在 [03_飞控配置与校准](03_飞控配置与校准.md) §2.2）→ **本册：连接、验收分级、日常操作、排障速查**。错误案例全量在 [11_错误与经验总结](11_错误与经验总结.md)。

## 1. 总则

- 家规：**任何新线缆上电前万用表两头逐针**；所有串口 TX/RX 交叉 + GND 共地；
- 三段无线电互不重叠：FS-i6 **2.4G** / 数传 **433M** / RTK LoRa **902~928M**；
- 排障心法：链路活性 → 口的身份 → 配置协议，分层判别（"无法配置"≠"链路坏了"）。

## 2. 数传（远航 3DR Radio X6，433MHz SiK 协议/X-Rock 4.0 固件）

> 数传 = 飞控↔地面笔记本之间的无线"串口线"。三件事：实时监控 / **侦察回传填单主通道** / 地面指令备份。三个"不是"：不传图像（空口 ~57.6kbps 只够遥测；图传上场前必须报备裁判）、不是遥控（控飞机的是 PPM 链路）、不参与飞控计算（纯透传）。

### 2.1 安装与连接

1. 机载版（带 GH 插头/裸 TTL 的那只）接 TELEM1（接线卡见 02 册 §9.4）；**天线先拧紧再上电**（无天线发射可能烧功放——唯一易真损坏操作）；
2. 天线朝下或朝侧**露出机架边缘**，别贴碳板、别与电源线捆扎；
3. 地面版（USB/CP2102 驱动）接笔记本，认出 COM 口（本机固定 COM10）；
4. MP 右上角：选 COM10 → 波特率 **57600** → 连接；**一对出厂同 Net ID，无需配对**；
5. 验收：HUD 出姿态、地图出位置、RSSI 百分比显示。

### 2.2 验收分级（逐步拉远）

| 级别 | 场景 | 通过标准 |
|---|---|---|
| ① 台架 | 飞控仅 USB 供电 | MP 能收数、参数页能读 |
| ② 整机 | 6S 供电全系统 | 同上，且舵机动作/电机解锁时数据不断流 |
| ③ 拉距离 | 场地目视范围 | 链路质量稳定，RSSI 衰减合理 |

（端到端验收已通过：心跳 1Hz 全链飞控→TELEM1→机载台→433→地面台→COM10。）

### 2.3 电台参数与频点（平时零维护）

- **日常无需配置**：出厂配对完好，只有赛场撞频才动手（改 **Net ID**，两端同步）；
- ⚠️ **MP 1.3.83 的 SiK 电台页对本电台定案不可用**：即使口/波特率/静默全对，"加载设置"必崩——页面全空、异常弹窗都是这一个原因，与链路健康无关；
- **改参数正解（静默配置四步法）**：
  1. 给机载端**断电**（链路静默是前置——X-Rock 固件进配置要 `+++` 前后 ~1s 串口静默，心跳每 0.97s 一帧永远打断它）；
  2. MP 电台配置页**必须选 COM10 且不点"连接"**（COM5 是飞控 USB，选错=AT 指令发给飞控）；
  3. 跑 `check_radio.py` 核身：`ATI` 应答 **X-Rock 4.0** = 电台活着、AT 通道可进；
  4. 改参数用 **3DR Radio Config** 独立工具；**严禁发 ATI5**（固件挂死全哑，重插 USB 恢复）。

### 2.4 比赛角色：侦察回传填单链路

```
机上 Jetson(TELEM2 @921600) → 飞控 MAVLink 桥接 → TELEM1(@57600)
  → 机载数传 —433MHz→ 地面数传(USB) → Mission Planner → 组员填单
```

- 填单员分工：一人看链路与飞机状态，一人按消息填单；**不要盯着地面站"开飞机"**——飞机是自主的；
- 断链预案：`FS_GCS_ENABLE=0` 机载自主兜底；数传异常**不要急着重启折腾链路**，先保任务。

### 2.5 排障速查

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 下拉里没有 COM 口 | 驱动没装 / 换了 USB 口 | 装 SiLabs VCP 驱动 |
| 连接超时 | 波特率不是 57600 / 口选错 | §2.1 核对 |
| 连上但 HUD 全空 | 机载版没插 TELEM1 / 天线没装 | 查接线与天线 |
| **单向通**（地面能注入、心跳回不来） | **TX/RX 没交叉** | 地面注入 PARAM_REQUEST_READ，飞控在 USB 口应答正常 = 半根线通；对调信号线秒通 |
| **SiK 电台页全空** | 口选错（COM5）+ MP 与 X-Rock 不兼容 | 别用 MP 电台页；走 §2.3 四步法 |
| **电台对一切 AT 全哑** | 被不支持指令挂死（ATI5） | 重插地面 USB 棒恢复；只用白名单指令 |
| RSSI 很低 | 天线被碳架遮挡 / 与电源线捆扎 | 重走线，天线露出机架外 |
| 一会儿断一会儿好 | 邻场同频干扰 | 改 Net ID 错开 |
| 拉远就断链 | 超链路余量 | 任务半径 300m 内标称 2km 有大余量，先查天线 |

## 3. RTK（瑞杰 RTK-01，备用/测试链路）

> ⚠️ **定位策略**：SSOT 定案主定位 = NEO-3 GPS + 视觉 + 激光（冠军队 Fix 收敛 3h37m 的教训）。本设备**只做测试/备份**，比赛是否启用默认否，启用须过 §3.4 五条件。
> ⚠️ **硬件现状：rover（RTK-01-R）串口输出硬件损坏存疑，封存待售后**（09-17：GPS2 座/Type-C/telem2 三通道全零字节，GNSS 引擎活=LED 闪；前科吻合 5V 撞 GND）。恢复前本节仅作档案与售后对照。

### 3.1 架构（与教科书 RTK 不同）

改正链路**自包含**：基站 RTK-01-B --LoRa 902~928MHz--> 机载 RTK-01-R --NMEA @921600--> V6X GPS2。基站独立工作（供电即 survey-in，完成后自动发改正，**全程不需笔记本**）；433 数传零占用。

### 3.2 配置要点

| 端 | 操作 |
|---|---|
| 基站 B | 天线拧上，架高 1.5~2m、天顶开阔、远离反射面；Type C 供电（充电宝可带 260mA）；**上架后全程禁动** |
| 机载 R | 接 GPS2（接线卡 02 册 §9.3，**循环移位映射**）；LED：LORA 亮=改正收到；RTK 灯=Fix 状态；PPS 闪=时钟锁定 |
| 飞控 | `GPS2_TYPE=3`(NMEA)、`GPS_AUTO_SWITCH=0`（只看不切）；本 beta 无 GPS2_BAUD——改 **SERIAL4_BAUD=921**；第三罗盘 QMC5883 设 **Yaw315°** 再校 |

⚠️ 参数配置一律走 `rtk_setup.py` 的**修正后版本**（现版 WANT 表 GPS2_TYPE=3 在本 beta 为已删除驱动，直接跑 `ops.py rtk` 会写坏 GPS2——待修）；改参数后**必须重启并回读**（参数改动后不重启就判 rover 无数据=曾造成外场误判"接线存疑"）。

### 3.3 验收分级（每次记录 Fix 收敛时间）

| 级别 | 场景 | 通过标准 |
|---|---|---|
| ① 台架 | 窗口/楼顶，基站架好 | RTK 灯 Fix（或 MP status=Fixed），记录收敛用时 |
| ② 静态对比 | 已测基准点上放 R | Fix 后读数与基准差 < 数 cm，10min 无漂移 |
| ③ 机上对比 | 与 NEO-3 并跑 | GPS1/GPS2 位置一致，EKF 无告警，全程 AUTO_SWITCH=0 |

### 3.4 比赛启用条件（缺一即维持纯 GPS）

- [ ] 台架收敛时间稳定在分钟级（≥3 次实测），非小时级
- [ ] 基站场地条件确认（赛前可提前架设完成 survey-in）
- [ ] 与 NEO-3 静态对比无整体偏移（"Fixed 但偏了"比 Float 更危险）
- [ ] 赛场 900MHz 环境实测无压制（LORA 灯常亮不闪断）
- [ ] 基站架设/看护专人（全程禁动）

### 3.5 排障速查

| 现象 | 最可能原因 → 处理 |
|---|---|
| rover 灯全不亮 | 供电反接嫌疑 → 立即断电，万用表逐针（循环移位映射见 02 册 §9.3） |
| 灯亮但 GPS2 无数据 | rover 串口输出损坏存疑（已封存）/ 线序 → 交叉验证排除线伤，售后送修 |
| Type C 无 NMEA | 正常——Type C 仅供电/APP 通道，NMEA 走 6P UART |
| 有 GPS 无 RTK（Float 不 Fix） | 基站没发 / LoRa 不通 → 看 B 供电与 R 的 LORA 灯 |
| LORA 亮但长浮不动 | 多径/遮挡 → 挪基站到更开阔处、架高 |
| Fix 后整体偏移 | survey-in 质量差或中途被动过 → 复位重新 survey-in，对基准点复测 |
| 罗盘校准不过 | 第三罗盘方向没设 → QMC 设 Yaw315 再校 |
| 波特率扫描全零别当结论 | "死模块"期间的扫描结果不算数——供电修好后按实际波特率重测定稿 |

## 4. GPS（CUAV NEO-3，主定位）

### 4.1 安装与认知

- 装 GPS1 口（**10P 原配线 1:1 直插**，安全开关/蜂鸣器随线），上桅杆远离干扰，箭头同机头；
- 罗盘勾选：**IST8310（外置）勾 External 当主罗盘；RM3100（板载）取消 External**；改后等 5 秒重启 + **重跑罗盘校准**；
- ⚠️ **NEO 3 Pro（M9N）物理不支持载波相位 RTK**——不存在"浮点升固定"路径，勿再追（真 RTK 唯 RTK-01，见 §3）；
- ⚠️ **fix_type 判读：0=没通信，1=搜星中**；室内 0 星属正常，勿误判坏件。

### 4.2 配置与验收

- 参数：`GPS1_TYPE=1`(AUTO)。⚠️ 勿设 5(NMEA)——NEO-3 是 UBX 协议，NMEA 驱动互聋（SIH 台架残留曾致"10Hz 报文在流但 0 星"）；也勿设 3（本 beta 已删除该旧 MTK 驱动）；`GPS_AUTO_SWITCH=0` 只看不切；
- 户外验收标准：**3D Fix + ≥8 星 + HDOP<1.5**；罗盘一致性复核与 GPS 出星同场做；
- 参数改动后回读核验并入全量备份（03 册 §2.2④）。

## 5. 激光定高（TFmini，串口版，TELEM3）

- 安装：下视方向（`RNGFND1_ORIENT=25`），`RNGFND1_GNDCLR` 按实际安装离地高度改（当前 0.1m 占位）；
- 接线：TX/RX 交叉 + 共地（卡见 02 册 §9.6，线色以实物手册为准勿凭记忆）；
- 参数：`SERIAL5_PROTOCOL=11`、`SERIAL5_BAUD=115`、`RNGFND1_TYPE=20`（25 是 I2C 版勿混）；TFmini 未装机期间 TYPE=0 临时禁用（03 册 §2.2 临时台账，装机后恢复 20/4 并两遍导入）；
- 作用：EK3_RNG_USE_HGT=4 时激光 4m 以下辅助定高（气压计在 2~5m 桨风下 ±0.5m 跳变不可靠）。

## 6. 自查题

1. 数传"完全无数据"第一步查什么？（单向通——注入测试定位，TX/RX 对调）
2. 电台配置为什么必须断机载端电？（X-Rock AT 门控要 +++ 前后 ~1s 静默，1Hz 心跳永远打断它）
3. RTK rover 正确接法一句话？（FC GPS2 第 k 针→rover 第 k+1 针循环移位；1:1 直通=5V 撞 GND）
4. NEO-3 能跑 RTK 吗？（不能——M9N 物理不支持载波相位；"浮点"实为 DGPS）
5. GPS fix_type=0 且 10Hz 报文在流，说明什么？（没通信——多半 TYPE 配错驱动互聋，不是在搜星）

# 07_工作日志 · 单文档制（2026-09-19 起）

## 约定

- **唯一工作日志 = [工作日志总编.md](工作日志总编.md)**：顶部目录（锚点+日期+一句话主题）→ 勘误链 → 待拍板清单 → 按日详录 → 未完成事项附录。
- **新会话写法**：在总编**文末**追加一节 `## 2026-MM-DD 主题短语`（绝对日期，禁"今天/昨天/最近"等相对时间词），并**同步更新总编顶部目录表**（加一行）。
- **错误与教训**：完整条目（日期/现象/根因/对策/防呆）沉淀到 `06_使用说明书/11_错误与经验总结.md` 对应模块；总编当日小节只写概要+指针。
- **方案状态**：里程碑/计划权威 = 根目录 `总体方案与执行计划.md` §11/§12；总编不另立方案。
- **按日历史原文**：2026-09-05 ~ 09-18 的 13 篇按日日志（含当日命令级细节）已整体迁入 `99_归档/工作日志按日版_20260919/`（只读不入库），由总编对应小节+指针反查。

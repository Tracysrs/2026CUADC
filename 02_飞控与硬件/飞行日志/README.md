# 02_飞控与硬件/飞行日志 · dataflash 日志存放处

> **本页索引**：用途与入库边界 → 命名规范 → 回拉流程 → 架次台账。
> 建立日期 2026-09-19（文档整理日）；首飞后本目录开始积累数据，台账随每次回拉登记一行。

## 1 用途与入库边界

- 本目录存放从飞控（Holybro V6X + ArduPilot 4.7-beta）回拉的 **dataflash 飞行日志原始 `.BIN` 文件**及其解包/分析产物。
- **入库边界（红线）**：`.BIN` 及解包产物数十 MB 级，**只留本地不入库**（`.gitignore` 已按目录整批忽略，仅放行本 README）；本 README 中的**架次台账**是唯一入库的索引记录。
- 日志反映的结论（排障发现、参数验证结果）沉淀到 `07_工作日志/工作日志总编.md` 对应日期小节，本台账只留指针。

## 2 命名规范

```
YYYY-MM-DD_架次NN_目的.bin
```

- 日期 = 飞行日期（非回拉日期）；架次 NN 当日两位序号（01、02…）；
- 目的 = 简短中文短语，如 `手动首飞`、`悬停测振`、`投放验证`、`AUTOTUNE`。
- 同一架次如有解包产物，放同目录并以同名前缀命名（如 `2026-09-19_架次01_手动首飞_事件表.csv`）。

## 3 回拉流程

1. 连飞控前先断开 Mission Planner（占 COM 口）；口不确定时先扫端口（设备管理器 / `Get-PnpDevice -Class Ports`）。
2. 回拉两条路任选：
   - **Mission Planner**：连接 → 日志页 → 下载全部/勾选日志；
   - **脚本**：`02_飞控与硬件/调试工具/ops.py` 统一入口（子命令见该目录 README）。
3. 回拉后按 §2 重命名，登记下方台账；飞行中发现的问题当天写进工作日志总编。
4. 完整操作步骤与判据见 `06_使用说明书/03_飞控配置与校准.md` 日志回拉节。

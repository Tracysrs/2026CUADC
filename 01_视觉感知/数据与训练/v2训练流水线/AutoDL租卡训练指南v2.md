## 1. 租实例（~10 分钟）

1. 注册/登录 [autodl.com](https://www.autodl.com)，充值 **¥20** 足够。
2. 算力市场 → **按量计费** → 显卡选 **RTX 4090**（3090 也够）。
3. **镜像**选框架镜像里的 **PyTorch 2.x + Python 3.10（CUDA 12.x）**——自带 torch，不用自己装。
4. 创建并开机，进入实例页，点 **JupyterLab**。

## 2. 上传文件（~10 分钟，视家宽）

上传到 JupyterLab 左侧文件树的 **`/root/autodl-tmp/`**（数据盘，空间大速度快）：

| 文件 | 是否必传 | 说明 |
|---|---|---|
| `real_data.zip` | **必传** | 240MB，已切分好的实拍数据集（414 张图 + 标签 + data.yaml） |
| `run_v2_training.sh` | **必传** | 一键训练脚本 |
| v1 的 `best.pt` | 三选一 | 见下表；脚本会自动找 |
| `hazard_labels_v2_11class.tar.gz` | 可选 | 仅当 v1 权重实在找不到时传，脚本自动先训 v1 再微调 |

**v1 权重三选一**（脚本按此顺序自动寻找）：

1. 上次 v1 交付的 `best.pt` 改名为 **`v1_best.pt`** 上传（推荐）
2. 直接以 **`best.pt`** 名义上传
3. 上传上次的 **`deliver_v1.zip`**（脚本自动解压提取）

哪个都没有？把合成数据 `hazard_labels_v2_11class.tar.gz`（274MB）也传上来，脚本会先自动训 v1（任务书 §1~§5 流程）再接着微调。

## 3. 一键训练

JupyterLab 里 **Terminal** → 粘贴执行：

```bash
cd /root/autodl-tmp && bash run_v2_training.sh
```

脚本自动完成：GPU 检查 → 装 ultralytics → 解压校验 414 张图/标签 → 定位 v1 权重（找不到会给出明确提示）→ 按任务书 §6 参数铁律微调 150 轮 → 逐类验收自动判读 → 打包交付物。

训练时别关网页。全程预计 30~60 分钟（含环境安装）。

**参数铁律**（已写死在脚本里，别改）：
- `lr0=0.001`：微调必须在预训练权重上降 10 倍学习率
- `flipud=0.5`：俯视图上下翻转是白赚的数据增强
- `hsv_h=0.005`：**色相就是类别特征**（红=易燃 橙=爆炸品），默认 0.015 会制造标签噪声
- `close_mosaic=10`：最后 10 轮关 mosaic 贴合真实分布

## 4. 取结果

跑完在 JupyterLab 文件树找到 **`/root/autodl-tmp/deliver_v2.zip`**，右键 Download。内含：

| 文件 | 用途 |
|---|---|

终端最后会打印"逐类验收判读"表，不达标的类别直接标了出来。

## 判读速查

- 脚本最后的判读表显示"全部类别达标" → 交付。
- 某一类显著偏低 → 先看混淆矩阵它和谁混；再确认该类 val 实例数（val 每类只有 9~32 个，单类偶发波动正常，别急着下结论）。
- **小目标漏检普遍偏高**（远处小桶检出不了）→ 可试 `imgsz=1280` 重训（把脚本第 5 步 imgsz 改掉），代价是 Jetson 端推理变慢，改之前先和部署端对齐。
- 某一类 mAP50=0 之类断崖 → 八成是标签类别号错位，抽查几张图的 txt 与实际贴纸对照。
- OOM（4090 基本不会）→ `batch=8` 重跑。
- 想从头再来 → 先 `rm -rf runs real_data` 再跑脚本。

## 与 v1 流程的差异

- 数据集换成本批实拍（414 张，按视频片段切分，验证集无泄题）；`data.yaml` 不含 `path` 键，换机器不用改路径（v1 的坑①不存在）。
- 训练方式从"从头训"改为"从 v1 best.pt 微调"，学习率与增强参数按任务书 §6 铁律收紧。
- 验收线从合成集 mAP50≥0.97 改为实拍集逐类 mAP50≥0.90（逐类无豁免）+ 漏检率<5%；注意任务书要求最终以**现场验证集**为准，本 val 是赛前代理指标。

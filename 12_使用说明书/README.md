# 12_使用说明书 · 模块化整合版

> 本目录把全部工作记录、方案文档、代码与日志**按学科模块整合**成套（2026-09-12 重组：原 15 份按设备/环节拆的分册，整合为 8 份按学科归类的模块文档；旧分册移入 `99_归档/使用说明书分册版_20260912/` 备查）。
> **编写体例参照 HIT 冠军队 Re0 教程模式**：每册开头"怎样使用本文/材料边界"，概念→为什么→命令→源码逐段讲解→验收门→自查题，细节（参数表/消息定义/脚本讲解/公式推导）全部内嵌，不依赖读者翻源码。
> 内容全部来自一手材料：`01_设计/总体方案与执行计划.md`（SSOT）、`09_工作日志/`（09-01 ~ 09-12 全部会话）、`10_机载代码/` 文档与源码、`03_工具/` 脚本、`11_设备参数/`。
> **权威版本仍在各模块**：本目录与 SSOT / 日志冲突时，以 SSOT 和最新日志为准；本文负责"把事情讲清楚、把步骤串起来"。

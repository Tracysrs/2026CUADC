## 1. 阶段一：外场日采集（外场日总单 G1，目标 ≥600 张）

### 1.1 器材清单（出发前勾）

- [ ] 白筒三规格 × 各 ≥2 只：ø15 / ø20 / ø25cm，高 30cm（PVC/纸筒喷白漆）；**有条件带一只备用/侧倒演示筒**；
- [ ] 蓝底布（有效区色，面积 ≥3×3m 可摆三筒）+ 固定胶带/配重（户外防风）；
- [ ] 无人机 + Jetson + BL-500W-335（**相机必须是真机——训练分布=真机成像，手机凑数等于白拍**，01 视觉模块 §6.1 教训）；备用电池按飞行架次算；
- [ ] 笔记本（ssh Jetson 回看抽帧）+ 打印版附录 A 执行单。

### 1.2 曝光与飞行纪律（红线现状先行确认）

- **手动锁快门当前不可执行**：BL-500W-335 固件无视 exposure_time_absolute（SSOT §4.4 相机基线 ⚠️ 2026-09-13 实测开放风险，11 册风险 #2 待拍板）。处置按 09-27 定案口径：
  1. **拍摄以悬停定点为主**——运动模糊 px≈v×曝光×焦距÷高度，悬停 v≈0 直接规避，不赌快门；
  2. 飞行转场遵守**识别段速度硬包络 ≤2 m/s**（09-27 物理预算定案）；
  3. **顺带收户外日光 AE 证据**：每格回看记一格「AE 是否稳定/有无过曝」——这是 11 册风险 #2「豁免论证」最廉价的实证输入，拍白筒顺路完成。
- 每格拍完当场 ssh 回看 2~3 张：糊/过曝/构图不对**当场重拍**，离场后补拍成本翻倍。

### 1.3 拍摄操作（kacha 悬停连拍）

- 每格一个架次内完成：飞机定点悬停在目标高度 → Jetson `kacha 30 1`（30 张、1s 间隔 ≈ 半分钟），期间地面轻微挪筒/变换摆位；
- 高度读数以飞控相对高度为准（ odom / 地面站报数），**一格一行记进现场记录表**（附录 A）；
- **不要用 `--detect`**：现役 `best.engine` 是危化 recon，画框与白筒无关，徒增 CPU；
- 存储压力：1080p JPEG 0.2~0.4MB/张，700 张 ≈ 150~300MB，无压力。

### 1.4 拍摄矩阵与配额（矩阵原文照采集操作卡 §一，这里落成数量口径）

| 桶 | 内容 | 目标张数 |
|---|---|---|
| 主力 | 2.0m（搜索主高度）正俯视为主，布景单/双/三筒、遮挡、蓝地/灰地轮换 | ~260 |
| 高度补充 | 1.5 / 3.0 / 4.0m 各一批 | 各 ~60 |
| 斜视角 | 30~45° 入射、目标压画面边缘 1/3（跨高度计入上两行） | **占比 ≥20%（≥120）** |
| 布景专项 | 两筒近距 0.3~0.5m（独立性）、三筒全景（直径差判别） | ≥100 |
| 困难样本 | 硬阴影压住筒口特写 / 白筒打翻侧倒 / 地面标线+亮反光干扰块同框 | 各 ≥20 |
| 背景负样本 | 无筒帧（蓝地/灰地各半，含地面杂物干扰） | ≥40 |

判定口径：**总保存量 ≥600 + 斜视角占比 ≥20% + 三个困难专项各 ≥20 + 无筒帧 ≥40**（表中桶有交叠，按去重后计）。
地面覆盖是硬要求：蓝地（自带布）+ 灰地（水泥/浅灰，"以现场为准"）各 ≥200 张；光照三档（阴/晴硬阴影/傍晚低角度）尽量全沾，晴天硬阴影是必拍项。

### 1.5 片段与命名纪律

- kacha 文件名 `HHMMSS_NNN.jpg` **天然成片段**（同一次连拍=同片段），`build_barrel_dataset.py` 的 fragment 切分直接识别，无需重命名；
- **不同布景/地面/光照之间停 ≥10s 再拍**（片段边界清晰 = 切分不跨域，沿 v3.2 三时段块纪律）；
- 同一格内 30 张连续帧相似度高，**挑帧阶段再隔 5~10 帧取一**（标注操作卡 §五纪律），拍摄阶段只管拍足。

### 1.6 终验考试集（M2 判分集，独立保留——本方案的验收根基）

- 外场**收尾时段**（与训练数据时段相隔最远、光照/布景最接近比赛态）专门拍 **60~100 张**：覆盖全部矩阵格 + **无筒负样本 ≥20 张**；
- 整段**不进 train 也不进 val**，单独目录保存，作为 M2「实拍白筒检出 ≥95%」与拒识判据的判分集（SSOT §8.3「现场实拍验证集必须独立保留」的落法）；
- 同样要标注（判分需要 GT），标注规范与阶段二相同。

### 1.7 离场前验收自检（照采集操作卡 §四，全勾才收工）

- [ ] 三种筒径各有 ≥150 张有效实例？（三规格均衡，别让 ø15 独大）
- [ ] 斜视角样本占比 ≥20%？
- [ ] 硬阴影 / 侧倒筒 / 干扰白块三类困难样本各有？
- [ ] 蓝地+灰地、三档光照都覆盖？
- [ ] 考试集已拍且时段独立、记录表已拍照存档？
- [ ] 原片已从 Jetson 拷出双份（笔记本 + U 盘/网盘）才算离场？

### 1.8 同场顺路任务（不混口径）

H 圆 ~200 张（hmarker 线）与危化补数（刺激性/放射性蓝地 + 蓝地背景 + 爆炸品专项，采集操作卡 §三）同场另线执行，由外场日总单统筹；**它们不进 barrel_seg_v2，600 张口径不含它们**。

## 3. 阶段三：建集 barrel_seg_v2 与 AutoDL 重训

### 3.1 建集（Windows 本机）

```bash
cd 01_视觉感知/数据与训练/barrel_seg_tools
python build_barrel_dataset.py \
    --synth ../barrel_work_20260930/synth_barrel \
    --real  ../barrel_h_ready_20260929/barrel_seg_ready \
    --real-extra ../barrel_外场MMDD/picked \
    --out   ../barrel_seg_v2 \
    --pin-train 0031 \
    --version barrel_seg_v2_YYYYMMDD
```

- 沿用 v1 全部家底（合成 1500 + 实拍 48 + 背景 114）+ 外场新集；`--pin-train 0031` 照旧钉扎（同批拍摄防 val 泄漏）；外场若有与 v1 实拍同源的片段号冲突，改外场片段前缀避让；
- **切分纪律**：实拍按片段 12% val；外场帧在拍摄时已按 ≥10s 时段块分组，val 必须自然含外场帧——⚠️ data0930 事故根因就是 val 与训练同域同渲染（零暴露），此处不许任何「外场全进 train」的走捷径操作。

### 3.2 打包上传（AutoDL 流程照《AutoDL跑白筒seg与H圆v1.md》§1~2）

- **待写工具** `run_barrel_v2_autodl.sh`（本目录，打包前就位）：以 v1 一键脚本为底——**EXPECT 计数改为 v2 建集审计值**（旧 1568/94 硬编码不符即拒跑的护栏要保留）、砍掉 hmarker 步骤、zip 名对齐 v2；预训练权重 yolov8n-seg.pt 继续随包（不依赖 GitHub 直连）；
- `_make_upload_bundle.py` 同步适配（脚本版本标记 + 总包结构断言 + 新对账数）；
- 总包预计 400~500MB（v1 为 279MB），上传 /root/autodl-tmp/ 解压。

### 3.3 训练（AutoDL 4090 按量计费）

- 镜像 PyTorch 2.x + Python 3.10（CUDA 12.x）；只跑白筒 seg 一条线；
- **参数铁律一个不动**（SSOT §8.2 + 脚本写死）：`100ep / imgsz 640 / batch 16 / seed 0 / flipud 0.5 / hsv_h 0.005 / close_mosaic 10`；
- 预计 100ep 45~70 分钟（v1 1662 张 30~50 分钟，v2 约 2200 张），全程 ≤2h ≈ ¥3~5；
- ⚠️ 若有人提「顺手改 imgsz 832」：推理尺寸改动必须与训练、部署端同批决策（危化 832 教训：强绑定、须另建 engine），本版不掺——保持 640 与 bucket_perception_params.yaml `imgsz: 640` 同构。

### 3.4 取件归档（关机纪律照 AutoDL 指南 §5）

- 下载 `deliver_barrel_v2.zip` → best.pt 与包内 SHA256SUMS 逐字节核对 → 归档 `deliver_work/deliver_barrel_v2/`（白名单外）；
- **台账双镜像**补 `barrel_seg_v2` 条目：`01_视觉感知/数据与训练/deliver_v2/dataset_version.md` 与 `hazard_hgd_10cls_v2/dataset_version.md`（两文件 CRLF，**字节级编辑零裸 CR**，改完核对 diff 行数）；
- 确认归档后再关机 → 释放实例。

## 6. 风险与预案

| 风险 | 预案 |
|---|---|
| 手动锁快门不可执行（11 册 #2） | 悬停拍摄规避模糊 + 户外 AE 证据顺带收集（豁免论证输入）；每格回看防过曝 |
| 外场地面单一 | 蓝底布自带保一路；灰地为硬要求项；草地可拍少量但不计入两路主口径 |
| 预标注高置信错标 | overlay 逐张目检 + audit + ≥10% 抽检（data0930 教训） |
| 片段泄漏/同域 val | 时段块 ≥10s 隔离；考试集整段独立；外场帧必进 val 不许全进 train |
| 对账不符拒跑 | 建集审计值出来后同步改 `run_barrel_v2_autodl.sh` EXPECT（护栏保留） |
| val 指标低于 v1 基线 | 外场真实域本来就难，先看 R 与跌幅；排查顺序=数据传错→泄漏→域难度；不断链就补数据迭代 |

| 上机影响生产 | bucket 槽独立、首次部署；recon `best.engine` 零改动；比赛日禁现场构建 engine |

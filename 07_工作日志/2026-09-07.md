## 四、ArduPilot SITL 装机 + M1 三项验收 ✅（追加）

**装机**（Jetson 无 sudo/apt，纯 g++ 源码编译）：
- 本机浅克隆 ArduPilot（1.5G 含子模块，Jetson 直连 GitHub 不通）→ tar 推送
  ~/ardupilot → `./waf copter` **6min29s 编译成功**（build/sitl/bin/arducopter）
- 踩坑：Windows autocrlf 把 waf 变 CRLF（shebang 失效，sed 剥 CR）；浅克隆无
  tags 致 git describe 失败（本地打 tag）；新版 SITL 必须显式 `--model quad`

**链路排障**（三个连环坑，最终形态 = `scripts/m1_sitl_accept.sh` + `scripts/gcs_pump.py`）：
1. DDS 发现失败（Jetson WiFi+RNDIS 多网卡组播跑错口）→ `ROS_LOCALHOST_ONLY=1`
2. ArduPilot 不流送遥测——端口上见到 **GCS 心跳**才开始流送，而 mavros 不冒充
   GCS → mavros 开 `gcs_url:=tcp-l://0.0.0.0:14550` 桥 + pymavlink 心跳泵
   （必须先发后收）；SR0_* 流送组用 `--defaults` 参数文件设 10Hz
3. CLI 偶发 DDS 挂死 → 服务调用一律 `timeout 15` + 3 次重试；脚本禁 `set -u`
   （与 ROS setup.bash 冲突）；pkill 模式写 `arducopte[r]` 防自匹配

**M1 验收结果（m1_sitl_accept.sh，Jetson 实测）**：
- **A 全流程 PASS**：WAIT_FCU→…→TAKEOFF→SEARCH(弓字)→RECON(6 点握手兜底)
  →RETURN→LAND→DISARM→DONE，"任务结束: 投放 0/2"（M1 演练模式正确行为）
- **B 接管保护 PASS**：TAKEOFF 中切 ALT_HOLD → 立即 PILOT_OVERRIDE 停发退让
- **C 断定位 PASS**：SIGSTOP 冻结 SITL → `MISSION_FAILURE: Odometry stale`
- 根 README M1 → 🔶 SITL 三项通过，待真机首测（拆桨）

## 1. 日常连接与运维基础

### 1.1 Windows 侧（飞控台架）

- 工具目录：`02_飞控与硬件/调试工具/`（pymavlink + pyserial，`pip install pymavlink pyserial`）；
- 飞控 USB 连电脑枚举 COM 口（默认 COM5）；接电池瞬间串口可能抖断一次，脚本已容错重连；
- 软重启可能卡 bootloader（COM 口变"无名 USB 设备"）——**拔插 USB 即恢复，参数不丢**。

### 1.2 Jetson 侧（机载电脑）

```bash
ssh jetson            # 别名指向 Jetson 当前 IP（热点切换会变，连不上先扫 22 端口），ed25519 免密
```

- **走局域网，别走 USB RNDIS**（阵发丢包 60%+，仅应急）；
- 串口设备：udev 别名 `/dev/cuadc-fc → ttyACM0`、`/dev/cuadc-fc2 → ttyACM1`（规则用 **ENV 属性匹配** `ID_SERIAL_SHORT` + `ID_USB_INTERFACE_NUM`，ATTRS 匹配实测不生效）；
- ⚠️ **必须禁用 ModemManager**（udev 事件后抢串口约 20s）：`sudo systemctl disable --now ModemManager`；
- 验证：`ls -l /dev/cuadc-fc` 后 3s 应能收到 MAVLink 字节流。

## 2. 飞控操作全流程

### 2.1 固件

- 板型实锤：`board_version=0x1B59`（board_id 7001）= **V6X v2**；⚠️ **v1 与 v2 载板通用但固件互不兼容，切勿刷 Pixhawk6X（v1）稳定版**；
- 在用：官方 beta `arducopter_beta_CUAV-V6X-v2.apj`（git **dbe79216**，存档 `02_飞控与硬件/firmware/`，飞行版 4.7.1-dev 在板）；回退备用：CUAV 编译版 `arducopter_CUAV_AP4.6.3.apj`；另存 SIH 台架固件（**禁外场**，09-17 拍板留档不刷）；

### 2.2 参数体系（4.7-beta 两大特性 + 基线全文）

**① 新一代参数命名（SI 单位后缀）——写旧名会被静默忽略**（回读应答超时而非报错）：

| 旧名（资料/老固件常见） | 本固件实名 | 说明 |
|---|---|---|
| WPNAV_SPEED | `WP_SPD`（m/s） | GUIDED 速度也归它管（GUIDS_* 整组取消） |
| LAND_SPEED | `LAND_SPD_MS`（m/s） | |
| FS_GCS_ENABL | `FS_GCS_ENABLE` | |
| BATT_LOW / BATT_CRT | `BATT_LOW_VOLT` / `BATT_CRT_VOLT` | 写旧名静默失效 |
| GUIDS_ANGLE | `ATC_ANGLE_MAX` | **单位已改"度"**：写旧值 3500 触发 PreArm "must be >= 10 and <= 80"，应写 35 |
| ATC_ACCEL_R/P/Y_MAX | `ATC_ACC_R/P/Y_MAX` | 角加速度 centideg/s²→deg/s²（÷100）；是**角**加速度不是线加速度（MP 官方迁移 issue 在此有过单位笔误，勿照抄） |
| ARMING_CHECK | `ARMING_SKIPCHK` | **位语义相反**（旧 bit0=全部检查，新 0=不跳过）——数值禁互抄；本机现值 1280=室内跳 GPS 临时值，外场前 `restore_arming.py` 复原 |
| PSC_POSXY/VELXY/ACCZ… | `PSC_NE/D` 系列 | 名称+单位+部分增益缩放同时变，**禁整组乘同一比例换算**（Re0 §5/附录 B.4，只读区） |

另：这版**没有任何 `COM_` 前缀参数**（`COM_RC_IN_MODE` 不存在）、**没有 SR0_\* 流送参数**、**没有 GPS2_BAUD**（GPS 口波特率跟底层串口 SERIAL4）。全参数快照 `02_飞控与硬件/调试工具/_param_dump.txt`（09-09 改动**前**的快照，对账时注意），查参数名以它为准。

**② 懒加载参数组 → 参数必须导入两遍（中间重启）**：`RNGFND1_*`、`PLND_TYPE` 等在功能开启并重启前**不存在**于参数表；反向也成立（`RNGFND1_TYPE=0` 时其子参数从表里消失，参数总数 1086→1071 是这个原因，对账遇计数差异先想到懒加载，不是丢参数）。

### 2.3 电池与解锁电压（6S 专属）

- 出厂默认 3300mAh/10.5V 是 3S 值；本机 6S 8000mAh（标称 22.2V，满电 25.2V）；
- 三级阈值：低电 21.6 → **RTL**；严重 21.0 → **Land**；解锁门槛 `BATT_ARM_VOLT=22.5`；
- **22.5 的区间推理**（为什么不设 24.5 也不设 21.8）：
  - 下限 = 低电阈值 21.6 + 悬停带载压降（6S 8000 约 0.6~1.0V）≈22.5——低于它解锁后一上负载就跌进低电区，起飞即触发失效保护；
  - 上限 ≈23.8——再高短飞落地（静止 ~23.2-23.5）无法复飞（**首版 24.5 的教训：只有近满电能解锁**）；
  - 22.5 = 标称与存储之间：存储态 22.92V 可解锁；刚触发严重保护落地的电池（静止回升 ~22.0-22.2）拒绝解锁，**强制换电**——这是设计行为不是故障；
- 压降为估算值，系留试飞时看悬停带载电压校核，必要时微调。

### 2.4 电机测试（拆桨，未解锁也能测）

```bash
python 02_飞控与硬件/调试工具/motor_test.py COM5 [输出口]
# 全测 M1→M4；python motor_test.py COM5 3 只转 M3
```

**脚本内部三道核验**（防"看着按序实际点错口"）：

1. **机架换算表**：读 FRAME_CLASS/FRAME_TYPE 查内置表取"输出口→测试序列号"映射（四轴 +/X 两种，其他机架直接拒绝）；
2. **输出口绑定**：逐个读 SERVO1~4_FUNCTION，必须 = Motor1~4(33~36)，否则拒绝盲测——`DO_MOTOR_TEST` 按"电机"寻址，绑定不对时"按序"是假象；
3. **安全开关代解**：自动发 `MAV_CMD_DO_SET_SAFETY_SWITCH_STATE`(5300) param1=1 解**会话**安全锁（`BRD_SAFETY_DEFLT` 只管开机默认，会话内状态独立）。

其他行为约定：

- ⚠️ param1 是**测试序列号不是输出口**（Quad X 序列 = 前右→后右→后左→前左，直接发 1~4 表现为"顺时针绕圈"点亮，是固件设计行为别误判接线错）——脚本内置 `OUT2SEQ={1:1,2:3,3:4,4:2}`；
- 顺序强制：升序去重；每台等满转 1s + 间隔 2.5s；中途被拒立即停；开跑前 3 秒倒计时；
- ⚠️ **只插 USB 不接电池时电机测试无效**（电调无主电）；
- 方向修正：对调该电机三根相线中任意两根（方向表见 [02_装机接线](02_装机接线.md) §5）。

### 2.5 校准（一律走 Mission Planner GUI！）

⚠️ 本 beta 对裸 `MAV_CMD_PREFLIGHT_CALIBRATION` 回 COMMAND_ACK ACCEPTED 但**静默不执行**——**校准别用裸 MAVLink**。

**① 无线电校准（RC）**——ESC 校准的前置：MP → 初始设置 → 必需硬件 → 无线电校准（前置 = PPM 链路已通）。同一套 FS-i6+iA6B **换飞控可不重做**：直接导入 `02_飞控与硬件/RC标定_iA6B.param`（自 2026-09-17 备份迁移的标定值 + RC_OPTIONS=32，2026-09-19 新板已导入验证；日后若重做 MP 校准以新值为准）。

**② 加速度计 + 罗盘**：

1. MP 六面校准；完成后报 "requires reboot" → 重启加载生效（实测罗盘偏置落盘、姿态 roll +0.2°/pitch +0.9° 稳定）；
2. 验证：PreArm 的 Accel/Compass 告警消失；
3. 罗盘勾选：**IST8310（NEO-3 外置）勾 External 当主罗盘；RM3100（V6X 板载）取消 External**——勾反 = 板内受扰罗盘当主用 = 航向漂/EKF 拒定/炸机；改完 Reboot **必须重跑一遍校准**（改勾选的参数写入后等 5 秒再重启）；
4. ⚠️ MP 校准进度条"满了归零重来" = 拟合拒绝自动重采（转太快/磁干扰），非故障；室内钢筋环境 Z 轴偏移可能偏大（经验值 <150），解锁一致性检查过了就能用，户外重校兜底（当前挂账：首飞前必做罗盘校准）。

**③ ESC 油门行程校准**（参数法定案，免 MP 向导，推荐固化）：

1. 前置：**无桨**、无线电校准已完成、机体压稳；
2. MAVLink 写 `ESC_CALIBRATION=3`（**等 5 秒刷存储**）；
3. 拔电池**并拔 USB** → 只接电池 → 电调自动学行程：听"音乐音 + 2 滴（满行程）→ 6 滴（6S 每芯）→ 1 长音（完成）"；
4. 参数自动归零，回读确认；
5. 验证：解锁慢推油门，四电机齐转、响应一致（motor_test.py 复核）；
6. ⚠️ 校准完成后飞控自动重启一次可能**卡死 + 残留假 PreArm**（Baro not healthy / Battery failsafe）——**彻底断电复位 + 1 分钟预热一招清**，不是坏件。

### 2.6 解锁

**桌面 STABILIZE 解锁**（非位置模式，强制层豁免；✅ 已实测零拒绝）：

- 条件全绿：电压 ≥22.5V、加速计 ✅、罗盘 ✅、RC 健康、电机参数 ✅（MOT_SPIN 组）；
- 操作：左摇杆右下 2s 解锁（电机怠速），左下 2s 上锁；
- 排障（PreArm 拒绝逐条清；**抓拒绝原文要听满整个窗口**——COMMAND_ACK 比 STATUSTEXT 先到，只抓 ack 会误判）：

| 拒绝原文 | 根因 → 处置 |
|---|---|
| `Battery below min arming voltage` | 电压 <22.5V → 充电（存储态 22.9V 可解锁；刚触发严重保护落地的电池强制换电） |
| `Accels/Compass calibrated requires reboot` | 校准后没重启 → 断电重启 |
| `MOT_SPIN_ARM > MOT_SPIN_MIN` | 怠速参数孤儿值 → 成组写回 0.15/0.13 |
| `Motors Emergency Stopped` | 急停拨杆在触发位 → CH6 拨回低位 + 重新解锁 |
| `Compass not calibrated` | 重校罗盘（§2.5②） |
| `RC not found` / Radio failsafe | 接收机链路断 → 查 PPM 接线（[02_装机接线](02_装机接线.md) §6） |
| `Arm: Need Position Estimate` | **GUIDED 专属强制层**，桌面绕不过（见下） |

**GUIDED 任务链 = 另一回事，硬依赖位置源**：

- 4.7 固件强制层：`Arm: Need Position Estimate`（mandatory 检查，ARMING_SKIPCHK=-1 也跳不过）；
- 状态机路径同样卡 `WAIT_NAV_STABLE`：真机无 GPS 时 mavros local_position/odom 不出流（SITL 有仿真 GPS 所以能过）；
- 结论：**GPS 户外出星之前，GUIDED 全流程不可能真机跑**。别在桌面跟这条死磕。

### 2.7 遥控器端配置（FS-i6）

- 通道规划：CH1~4 摇杆；**CH5 = 飞行模式**（SWC 三段：Stabilize/AltHold/Loiter）；**CH6 = 急停**（SWA 两段，RC6_OPTION=31）；（2026-09-25 按实物勘正：FS-i6 出厂 SWA 两挡、SWB/SWC 三挡，旧文 SWA/SWC 写反）
- 开关分配在 AUX 菜单；**开关测试要做单开关单测**（混测+统计窗口曾把 SwA 余动作误判成 SwC）；
- ⚠️ **failsafe 必须改 No pulses**（RX SETUP → FAILSAFE；出厂"保持"会让飞控察觉不到断链）——挂账待做；
- 急停语义：SwA 高位(>1800) = 电机停转锁死；解除 = 拨回低位 + 重新解锁。

### 2.10 调参路线（滤波先行 + 双流程卡 + 载荷包络，2026-09-20 成文）

> 来源：SSOT §15-C1/C2/C5（Re0 飞控调试 §39~§52/§64、附录 F-09，只读区；完整参数表与算法推导在教程，引用需勘误旧口径）。

**顺序铁律：机械紧固 → 基本可飞 → 悬停日志看振动（VIBE/clip）→ 陷波设计 → 滤波验证 → 才允许自动整定。**
D 项对高频噪声敏感，滤波不当时整定会把噪声当振荡边界。`QUIK_AUTO_FILTER=1` 只按 INS_GYRO_FILTER 改部分 PID 滤波、且可能覆盖手动验证过的 FLTT/FLTD——**滤波归属预先决定：我们手动管滤波，`QUIK_AUTO_FILTER=0`**。
⚠️ 姿态/位置内环参数**不可从 SITL(Iris 1.5kg) 直接搬到 ZD550(8kg)**，两边只能互验逻辑；大风天不 tune；不在桶上方 1.3m 任务高度首调。

**滤波/陷波实操（2026-09-26 补全 C1 的步骤层；素材 Re0 §39+附录 C.5）**——顺序铁律中"陷波设计→滤波验证"的具体做法：

1. **取谱**：基本可飞后 1~2 分钟平稳悬停 → §2.9 回拉 BIN → `log_hover_check.py <BIN> --fft`（IMU 角速度频谱：默认日志只有数十 Hz 流，判 Nyquist 以内的控制振荡/结构晃动、整定前后对比）；**电机基频段（通常几十~两百 Hz）超出默认日志流**——定频用 MP 日志页 FFT（全速率批采样），批采样开启后工具升级挂账。
2. **定频**：随油门移动的峰=电机基频及其倍频（以实测为准）；位置固定的峰=结构谐振——**先紧机械再滤波**，高 D 压不住机械松动。
3. **设陷波**：`INS_HNTCH_ENABLE=1` + 按峰频设中心/带宽/衰减（MODE 等选项含义以本固件参数帮助为准，不抄网上数值）；有可靠 RPM 遥测再考虑跟踪模式；陷波不还原已削波（Clip>0）的数据。
4. **验证**：同条件复飞复拉对比——峰被压住、姿态响应无额外迟滞、电机温度不升；不达标回调。
5. **归属**：滤波参数人工管理（`QUIK_AUTO_FILTER=0`），整定后 `verify_params --diff` 确认 FLTT/FLTD/INS_GYRO_FILTER 未被顺手改掉。

**双流程卡（三选一原则：内置 AutoTune 与 Lua QuickTune 不可混用、不可同跑）**：

| 步骤 | 内置 AutoTune（AUTOTUNE_） | Lua QuickTune（QUIK_） |
|---|---|---|
| 入口 | AUTOTUNE 模式 / 辅助功能 17 | SD 卡 `APM/scripts/VTOL-quicktune.lua` + `RCx_OPTION=300`（QUIK_RC_FUNC=300） |
| 行为 | 主动施加测试动作辨识 | 悬停中渐进找角速度环增益边界 |
| **中止/回退** | 退出自动恢复原增益 | **只认开关 LOW + 亲见 "Tuning: reverted"**——QUIK_ENABLE=0、切飞行模式、pcall 报错都 ≠ 回退 |
| **保存** | **受控落地 disarm 时保存**（保持接受/测试状态落地） | **落地前切 HIGH、亲见 "Tuning: saved"**（先切 LOW 会先丢弃未存结果！） |
| 轴位掩码 | AXES 位0R/1P/2Y/3YawD | AXES 位0R/1P/2Y |

共同前置：原参数已导出（`verify_params --export`）；调参开关无桨台架逐位核对；先 SITL 练开关顺序；一次只跑一种。

**QuickTune 可用性前置核验（2026-09-26）**：本机 `SCR_ENABLE=0`（0924 全量 dump 实证），**Lua 路线当前不可用**。调参日前二选一：①只走内置 AutoTune——本机 AUTOTUNE_AGGR=0.075/AXES=7/GMBK=0.25/MIN_D=0.0005 与 Re0 固定 4.7.1 源码默认逐项一致（0924 dump），教程 §42/§46 参数表可直接对照，仍以实机读回为准；②启用 Lua 三件套——`activate_lazy_params` 确认 SCR_* 浮现 → 官方 VTOL-quicktune.lua 入 SD `APM/scripts/`（固定提交+校验值核对，Re0 §45 四项检查）→ 无桨台架绑专用三段开关（RCx_OPTION=300）。任一件不成立就地走①，不临场凑配置。

## 2. 行为澄清表（旧口径 → 现行事实，新人防误解）

| 旧口径 / 易误解 | 现行事实（实现位置见 11 册 §13.1） |
|---|---|
| "value_at 越界返回兜底值" | 重构时已消除该模式：越界 = 显式判空，无静默兜底 |
| "接收端把无效置信度改写为 1.0" | 无改写：低于 `min_detection_confidence` 直接跳过 pose；哨兵违约**整帧**拒用 |
| "服务超时只清本地 future，越等越卡" | 已修：request_id 归档 + 2s 超时 `remove_pending_request`，结果记未知 |
| "舵机被 FCU 拒绝照样计数" | 已修：拒绝 → sequencer 回退重投且计数不推进，连击 ≥3 弃任务；超时 = unknown 打标进 DONE 汇总 |
| "tick 先发旧目标、下拍才发新的" | 已修：publish 移到状态 switch 之后（当拍出） |
| "两个水平误差补偿后是同一个数" | 非同一向量：ALIGN 用活动估计，RELEASE 用冻结补偿点（含偏置+前移） |
| "门禁控制到物理脱离" | 口径纠正：八门控只到**发令前**；发令后仅两道收尾（2s 发送失败兜底、0.7s 回仓时序）——物理动作不可撤回 |
| "插值越界返回 fallback 值" | 拒绝即丢帧不外推：四种拒绝状态（空历史/未来戳/太旧/断流间隔），边界语义由 test_odom_interp 锁死 |
| "SEARCH 随时喂图随时能锁" | 有 `search_settle_s=8` 沉降期（EKF 飞行中罗盘对齐期喂图会凑出假航迹） |
| "对准丢视觉就按冻结坐标盲投" | 绝不：重捕获一次用尽即弃桶拉黑；RELEASE 另有 target_age ≤0.5s 反盲投独立把守 |
| "锁定排名随时可变、随时可锁" | 排名签名稳定 0.8s 才冻结；冻结参考永不被改写（重捕获只改 working 估计） |
| "第二目标时刻随视觉刷新" | arrival 保留旧时刻，防合成新鲜（冻结语义的一部分） |
| "rescue profile 会偷偷改参数" | 三包重构中已移除该机制；`ros2 param get` 即生效值（启动另有 effective config 打印） |
| "今天先跑通，参数回头再对" | 单因素变更纪律 + 两遍导入 + verify_params --diff + 启动指纹比对，四件缺一不可 |
